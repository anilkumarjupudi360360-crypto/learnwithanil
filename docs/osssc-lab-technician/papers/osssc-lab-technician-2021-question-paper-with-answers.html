  1. Q1 · Arithmetic · Arithmetic

    Which number should replace both the ‘*’ s in (*/18) × (*/162) = 1 ?

    1. 18
    2. 54
    3. 162
    4. 2916
    Show answer

    Answer: (2) 54

    (x/18)(x/162)=1 gives x^2 = 18*162 = 2916, so x = 54.

  2. Q2 · Arithmetic · Arithmetic

    If √5625 = 75, then find the value of √5625 + √56.25 + √0.5625

    1. 56.25
    2. 832.5
    3. 8.325
    4. 83.25
    Show answer

    Answer: (4) 83.25

    sqrt(56.25)=7.5 and sqrt(0.5625)=0.75, so 75 + 7.5 + 0.75 = 83.25.

  3. Q3 · Arithmetic · Arithmetic

    The H.C.F. of two numbers is 9. Which one of the following numbers can never be their L.C.M.?

    1. 36
    2. 54
    3. 66
    4. 81
    Show answer

    Answer: (3) 66

    The L.C.M. must be a multiple of the H.C.F. (9). 36, 54 and 81 are multiples of 9; 66 is not.

  4. Q4 · Arithmetic · Arithmetic

    Find the value of (0.67 × 0.67−2×0.67×0.52+0.52×0.52)/(0.67−0.52)

    1. 0.15
    2. 1
    3. 1.19
    4. 0.30
    Show answer

    Answer: (1) 0.15

  5. Q5 · Arithmetic · Arithmetic

    Of the three numbers, second is twice the first and is also thrice the third. If the average of the three numbers is 33, the largest number is:

    1. 18
    2. 27
    3. 54
    4. 81
    Show answer

    Answer: (3) 54

    Let first = x, second = 2x, third = 2x/3. Sum = 11x/3 = 3*33 = 99, so x = 27; largest = 2x = 54.

  7. Q7 · Arithmetic · Arithmetic

    Two numbers are in the ratio 4:5. If 24 is added to each number, the ratio becomes 6:7. The sum of the number is:

    1. 81
    2. 90
    3. 99
    4. 108
    Show answer

    Answer: (4) 108

    (4k+24)/(5k+24) = 6/7 gives 28k+168 = 30k+144, so k = 12; sum = 9k = 108.

  8. Q8 · Arithmetic · Arithmetic

    A grocer sells rice at a profit 20% and uses a weight which is 20% less. Find out overall gain percentage.

    1. 50%
    2. 40%
    3. 30%
    4. 20%
    Show answer

    Answer: (1) 50%

    He gives 800 g for the price of 1000 g plus 20%: cost 800, selling price 1200, so gain = 400/800 = 50%.
