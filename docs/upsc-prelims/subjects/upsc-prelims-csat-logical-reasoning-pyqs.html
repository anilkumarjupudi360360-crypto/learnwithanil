    There are four statements X, Y, Z and W. Their relations are as follows : If X is incorrect, then so is Z; if Y is incorrect, then W is correct; if W is correct, then X is incorrect. Which of the following is/are correct? I. If X is correct, then so is Y. II. If Z is correct, then it is not necessary that Y is correct. Select the answer using the code given below.

    1. I only
    2. II only
    3. Both I and II
    4. Neither I nor II

    चार कथन X, Y, Z और W हैं। उनके संबंधों का वर्णन निम्नलिखित है : यदि X गलत है, तो Z भी गलत है; यदि Y गलत है, तो W सही है; यदि W सही है, तो X गलत है। निम्नलिखित में से कौन-सा/कौन-से सही है/हैं? I. यदि X सही है, तो Y भी सही है। II. यदि Z सही है, तो यह आवश्यक नहीं है कि Y सही है। नीचे दिए गए कूट का प्रयोग कर उत्तर चुनिए।

    1. केवल I
    2. केवल II
    3. I और II दोनों
    4. न तो I और न ही II
    Show answer

    Answer: (1) I only

    उत्तर: (1) केवल I

  6. Prelims 2025 · CSAT · Q70 · CSAT: Logical & Analytical Reasoning · Logical Reasoning

    A question is given followed by two Statements I and II. Consider the Question and the Statements and mark the correct option. Question: How is Q related to P? Statement I: P has two sisters, R and S. Statement II: R’s father is the brother of Q. Which one of the following is correct in respect of the above Question and the Statements?

    1. The Question can be answered by using one of the Statements alone, but cannot be answered using the other statement alone.
    2. The Question can be answered by using either Statement alone.
    3. The Question can be answered by using both the Statements together, but cannot be answered using either Statement alone.
    4. The Question cannot be answered even using any of the Statements.

    एक प्रश्न दिया गया है, जिसके बाद दो कथन I और II दिए गए हैं। उस प्रश्न और उन कथनों पर विचार कीजिए और सही विकल्प को चिह्नित कीजिए। प्रश्न : Q, P से किस प्रकार संबंधित है? कथन I : P की दो बहनें, R और S हैं। कथन II : R का पिता, Q का भाई है। उपर्युक्त प्रश्न और कथनों के सन्दर्भ में, निम्नलिखित में से कौन-सा एक सही है?

    1. इस प्रश्न का उत्तर, इन कथनों में से किसी एक का अकेले उपयोग कर दिया जा सकता है, किन्तु दूसरे कथन का अकेले उपयोग कर नहीं दिया जा सकता।
    2. इस प्रश्न का उत्तर, दोनों कथनों में से किसी का भी अकेले उपयोग कर दिया जा सकता है।
    3. इस प्रश्न का उत्तर, दोनों कथनों का एक साथ उपयोग कर दिया जा सकता है, किन्तु दोनों में से किसी एक कथन का अकेले उपयोग कर नहीं दिया जा सकता।
    4. इस प्रश्न का उत्तर, इन कथनों में से किसी का उपयोग कर भी नहीं दिया जा सकता।
    Show answer

    Answer: (4) The Question cannot be answered even using any of the Statements.

    उत्तर: (4) इस प्रश्न का उत्तर, इन कथनों में से किसी का उपयोग कर भी नहीं दिया जा सकता।

  4. Prelims 2025 · CSAT · Q8 · CSAT: Logical & Analytical Reasoning · Series & Patterns

    What comes at X and Y respectively in the following sequence? January, January, December, October, X, March, October, Y, September

    1. July, May
    2. July, April
    3. June, May
    4. June, April

    निम्नलिखित अनुक्रम में क्रमशः X और Y के स्थान पर क्या आता है? जनवरी, जनवरी, दिसंबर, अक्टूबर, X, मार्च, अक्टूबर, Y, सितंबर

    1. जुलाई, मई
    2. जुलाई, अप्रैल
    3. जून, मई
    4. जून, अप्रैल
    Show answer

    Answer: (2) July, April

    उत्तर: (2) जुलाई, अप्रैल

    Each term is obtained by going back from the previous month by 0, 1, 2, 3, ... months in turn: January (back 0) January, (back 1) December, (back 2) October, (back 3) July, (back 4) March, (back 5) October, (back 6) April, (back 7) September. So X = July and Y = April. Check: four months before July is March and seven months before April is September, both matching the printed terms. June for X would need a step of 4, breaking the pattern.

    प्रत्येक पद पिछले पद से क्रमशः 0, 1, 2, 3, ... महीने पीछे जाकर मिलता है: जनवरी (0 पीछे) जनवरी, (1 पीछे) दिसंबर, (2 पीछे) अक्टूबर, (3 पीछे) जुलाई, (4 पीछे) मार्च, (5 पीछे) अक्टूबर, (6 पीछे) अप्रैल, (7 पीछे) सितंबर। अतः X = जुलाई और Y = अप्रैल। जाँच: जुलाई से चार महीने पहले मार्च और अप्रैल से सात महीने पहले सितंबर आता है, जो दोनों छपे हुए पदों से मेल खाते हैं। X के लिए जून लेने पर 4 का अंतर चाहिए, जिससे प्रतिरूप टूट जाता है।
