    1. 2((a + b)/(a − b))
    2. 4((a − b)/(a + b))
    3. 4((a + b)/(a − b))
    4. ((a + b)/(a − b))

    यदि x = (√a + √b)/(√a − √b) और y = (√a − √b)/(√a + √b) है, जहाँ a > b > 0 है, तब (x + y)/0.5 ज्ञात कीजिए।
