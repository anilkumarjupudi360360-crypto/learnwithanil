    Which one among the following statements is not correct?

    1. Assembler translates an assembly language program into a machine language program.
    2. Compiler is a program that translates high-level language into machine language.
    3. Assembly level program is a sequence of machine language instructions.
    4. The term 'firmware' is used for the software stored in read-only storage devices.

    निम्नलिखित में से कौन-सा कथन सही नहीं है?

    1. असेम्बलर किसी असेम्बली लैंग्वेज प्रोग्राम को मशीन लैंग्वेज प्रोग्राम में अनूदित करता है।
    2. कम्पाइलर एक प्रोग्राम है, जो हाई-लेवल लैंग्वेज को मशीन लैंग्वेज में अनूदित करता है।
    3. असेम्बली लेवल प्रोग्राम, मशीन लैंग्वेज अनुदेशों का एक क्रम है।
    4. रीड-ओनली स्टोरेज डिवाइसों में स्टोर किए गए सॉफ्टवेयर के लिए 'फर्मवेयर' शब्द प्रयुक्त किया जाता है।
    Show answer

    Answer: (3) Assembly level program is a sequence of machine language instructions.

    उत्तर: (3) असेम्बली लेवल प्रोग्राम, मशीन लैंग्वेज अनुदेशों का एक क्रम है।

    An assembly language program is a sequence of symbolic instructions (mnemonics such as ADD or MOV), not machine-language (binary) instructions; an assembler must translate it into machine code. The other statements are correct: assemblers and compilers translate into machine language, and firmware is software held in read-only memory.

    असेम्बली लैंग्वेज प्रोग्राम प्रतीकात्मक अनुदेशों (ADD या MOV जैसे निमॉनिक्स) का एक क्रम होता है, न कि मशीन लैंग्वेज (बाइनरी) अनुदेशों का; असेम्बलर को इसे मशीन कोड में अनूदित करना पड़ता है। अन्य कथन सही हैं: असेम्बलर और कम्पाइलर मशीन लैंग्वेज में अनुवाद करते हैं, और फर्मवेयर रीड-ओनली मेमोरी में रखा गया सॉफ्टवेयर है।
