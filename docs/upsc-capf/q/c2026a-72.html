  1. CAPF 2026 · P-I · Q72 · Geography · World Geography

    Which of the following countries share borders with Israel? 1. Egypt 2. Jordan 3. Syria 4. Lebanon Select the correct answer using the code given below.

    1. 1 and 4 only
    2. 1 and 2 only
    3. 2 and 3 only
    4. 1, 2, 3 and 4

    निम्नलिखित में से कौन-से देश इज़राइल के साथ सीमा साझा करते हैं? 1. मिस्र 2. जॉर्डन 3. सीरिया 4. लेबनान नीचे दिए गए कूट का प्रयोग कर सही उत्तर चुनिए।

    1. केवल 1 और 4
    2. केवल 1 और 2
    3. केवल 2 और 3
    4. 1, 2, 3 और 4
    Show answer

    Answer: (4) 1, 2, 3 and 4

    उत्तर: (4) 1, 2, 3 और 4

    Israel has land borders with Egypt (Sinai) to the south-west, Jordan to the east, Syria to the north-east (Golan Heights) and Lebanon to the north, so all four countries are correct.
