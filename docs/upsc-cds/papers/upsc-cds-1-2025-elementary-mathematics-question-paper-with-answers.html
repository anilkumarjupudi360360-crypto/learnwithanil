  1. Q1 · Algebra · Polynomials & Quadratics

    A real number M is squared to give the value N. What is the minimum value of (M + N)?

    1. −0·25
    2. −0·50
    3. 0
    4. 0·25
    Show answer

    Answer: (1) −0·25

    M + N = M² + M = (M + 1/2)² − 1/4, which is least when M = −1/2. So the minimum value is −1/4 = −0·25.

  2. Q2 · Arithmetic · Number System

    Show answer

  4. Q4 · Algebra · Equations & Expressions

    Let x, y, z be variables such that (x + y + z) = k, where k is a constant. If (x + z − y) × (x − z + y) is proportional to yz, then (y + z − x) is proportional to:

    1. x
    2. y
    3. yz
    4. xz
    Show answer

    Answer: (3) yz

    (x + z − y)(x − z + y) = (k − 2y)(k − 2z) = k(k − 2y − 2z) + 4yz = k(x − y − z) + 4yz. If this equals c·yz, then k(y + z − x) = (4 − c)yz, so (y + z − x) is proportional to yz.

  5. Q5 · Arithmetic · Number System

    Let p be the remainder when 7⁸⁴ is divided by 342 and q be the remainder when 7⁸⁴ is divided by 344. What is (p − q) equal to?

    1. 0
    2. 1
    3. 2
    4. 6
    Show answer

    Answer: (1) 0

    7³ = 343 = 342 + 1 = 344 − 1. So 7⁸⁴ = (343)²⁸ ≡ 1²⁸ = 1 (mod 342) and ≡ (−1)²⁸ = 1 (mod 344). Hence p = q = 1 and p − q = 0.

  6. Q6 · Arithmetic · Number System

    N is the smallest 5-digit number which when divided by 2, 2², 2³, 2⁴, …, 2ⁿ leaves a remainder 1. What is the value of n?

    1. 12
    2. 13
    3. 14
    4. 15
    Show answer

    Answer: (3) 14

    N − 1 must be a multiple of 2ⁿ. Taking N = 2ⁿ + 1 as the smallest 5-digit such number gives 2¹⁴ + 1 = 16385 (2¹³ + 1 = 8193 has only 4 digits), so n = 14. Strictly, n = 13 also leads to N = 16385, so the question is loosely framed; 14 is the intended answer. (Answer by Learn with Anil; UPSC has not published its key.)

  7. Q7 · Arithmetic · Number System

    What is the minimum value of p for which 1/532900 + p²/266450 + p⁴/523900 is an integer?

    1. 729
    2. 243
    3. 27
    4. 1
    Show answer

    Answer: (3) 27

    532900 = 730² and 266450 = 532900/2, so with the last denominator read as 532900 the sum is (1 + 2p² + p⁴)/730² = ((p² + 1)/730)². The least p with p² + 1 divisible by 730 is p = 27 (27² + 1 = 730), giving the integer 1. The last denominator printed as 523900 appears to be a misprint for 532900; as printed, none of the options gives an integer. (Answer by Learn with Anil; UPSC has not published its key.)

  8. Q8 · Algebra · Polynomials & Quadratics

    If α and β are the roots of the equation x + a + b = abx/(ab + ax + bx), then what is (αβ + α + β) equal to?

    1. ab + a + b
    2. ab − a − b
    3. a + b − ab
    4. −(ab + a + b)
    Show answer

    Answer: (2) ab − a − b

    Cross-multiplying, (x + a + b)(ab + (a + b)x) = abx simplifies to (a + b)[x² + (a + b)x + ab] = 0, so x² + (a + b)x + ab = 0. Then α + β = −(a + b) and αβ = ab, giving αβ + α + β = ab − a − b.

  9. Q9 · Arithmetic · Number System

    Consider a 2-digit number N. Let P be the product of the digits of the number. If P is added to square of the digit in the tens place of N, we get 84. If P is added to the square of the digit in the unit place of N, we get 60. What is the value of P + N?

    1. 100
    2. 110
    3. 115
    4. 120
    Show answer

    Answer: (2) 110

    With digits a (tens) and b (units): a² + ab = 84 and b² + ab = 60. Adding gives (a + b)² = 144, so a + b = 12, a = 84/12 = 7 and b = 5. Then N = 75, P = 35 and P + N = 110.

  10. Q10 · Arithmetic · Averages & Mixtures

    A mixture of 100 L contains kerosene and turpentine oil in the ratio 3 : 2. What is the minimum quantity of kerosene in litres (whole number) that should be mixed in the mixture so that the resulting mixture has 20% of kerosene?

    1. 10 L
    2. 20 L
    3. 25 L
    4. Not possible
    Show answer

    Answer: (4) Not possible

    The mixture already has 60 L of kerosene, which is 60%. Adding more kerosene can only raise this share, so it can never fall to 20%.
