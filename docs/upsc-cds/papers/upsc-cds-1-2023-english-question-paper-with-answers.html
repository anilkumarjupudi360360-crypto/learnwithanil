  1. Q1 · English · Parts of Speech

    Directions: Each of the following sentences has word/words underlined. Read the sentence carefully and find which word class the underlined word/words belongs/belong to. I like that boy. (underlined: that)

    1. Noun
    2. Demonstrative Pronoun
    3. Participle
    4. Conjunction
    Show answer

    Answer: (2) Demonstrative Pronoun

    "That" points out a particular boy, so among the options it belongs to the demonstrative class; strictly, since it stands before the noun "boy", grammars call it a demonstrative adjective/determiner rather than a pronoun, but UPSC's key takes the demonstrative option.

  7. Q7 · English · Parts of Speech

    Directions: Each of the following sentences has word/words underlined. Read the sentence carefully and find which word class the underlined word/words belongs/belong to. My sister is just sixteen and therefore not eligible to vote. (underlined: therefore)

    1. Gerund
    2. Adverb
    3. Adjective
    4. Conjunction
    Show answer

    Answer: (2) Adverb

    "Therefore" is a conjunctive adverb showing consequence; the actual joining word here is "and", so "therefore" is an adverb, not a conjunction.
