  1. Q1 · Arithmetic · Number System

    Two positive integers x and y are in the ratio 17 : 19. If the LCM of the two numbers is 1615, then what is (x + y) equal to?

    1. 36
    2. 180
    3. 360
    4. Cannot be determined due to insufficient data
    Show answer

    Answer: (2) 180

    Let x = 17k and y = 19k; since 17 and 19 are co-prime, LCM = 323k = 1615, so k = 5. Then x + y = 36k = 180.

  2. Q2 · Algebra · Equations & Expressions

    If p/q = q/r = r/s = k, then what is (p³ + q³ + r³)/(q³ + r³ + s³) equal to?

    1. p/s
    2. r/q
    3. s/p
    4. q/r
    Show answer

    Answer: (1) p/s

    Each term of the numerator is k times the matching term of the denominator (p = kq, q = kr, r = ks), so the ratio is k³. Also p/s = (p/q)(q/r)(r/s) = k³, so the answer is p/s.

  3. Q3 · Algebra · Polynomials & Quadratics

    If x² − 4x + 3 is a factor of x⁴ + px² + q, then what is (p − q) equal to?

    1. −19
    2. −17
    3. 17
    4. 19
    Show answer

    Answer: (1) −19

    x² − 4x + 3 = (x − 1)(x − 3), so x = 1 and x = 3 are zeros: 1 + p + q = 0 and 81 + 9p + q = 0. Subtracting gives 8p = −80, so p = −10, q = 9 and p − q = −19.

  4. Q4 · Algebra · Polynomials & Quadratics

    Suppose p and q are positive integers where q is not a perfect square. If 1/(p + √q) is a root of a quadratic equation having integer coefficients, then which of the following statements is/are correct? I. The sum of the roots is 2p times the product of the roots. II. The sum of the reciprocals of the roots is equal to 2p. Select the answer using the code given below:

    1. I only
    2. II only
    3. Both I and II
    4. Neither I nor II
    Show answer

    Answer: (3) Both I and II

    The roots are (p − √q)/(p² − q) and its conjugate (p + √q)/(p² − q), so sum = 2p/(p² − q) and product = 1/(p² − q); sum = 2p × product (I true). The reciprocals of the roots are p + √q and p − √q, whose sum is 2p (II true).

  5. Q5 · Algebra · Equations & Expressions

    If 1/(2b + 2c) + 1/(2c + 2a) = 1/(a + b), then what is a² + b² + c² equal to?

    1. 9c²
    2. 4c²
    3. 3c²
    4. 2c²
    Show answer

    Answer: (3) 3c²

    Clearing denominators: (a + b)(c + a) + (a + b)(b + c) = 2(b + c)(c + a), i.e. (a + b)² + 2c(a + b) = 2c² + 2ab + 2c(a + b), which gives a² + b² = 2c². Hence a² + b² + c² = 3c².

  6. Q6 · Arithmetic · Speed & Distance

    A train completely crossed two persons X and Y moving in the same direction as the train in 8 seconds and 8·1 seconds respectively. X is walking at a uniform speed of 3 km/hr and Y is walking at a uniform speed of 4 km/hr. What is the speed of the train?

    1. 81 km/hr
    2. 82 km/hr
    3. 83 km/hr
    4. 84 km/hr
    Show answer

    Answer: (4) 84 km/hr

    The train's length is the same in both cases: (v − 3) × 8 = (v − 4) × 8·1, so 8v − 24 = 8·1v − 32·4, giving 0·1v = 8·4 and v = 84 km/hr.

    1. 6
    2. 24
    3. 60
    4. 120
    Show answer

    Answer: (3) 60
