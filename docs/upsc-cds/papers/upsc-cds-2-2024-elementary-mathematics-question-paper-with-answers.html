  1. Q1 · Algebra · Polynomials & Quadratics

    A real number x is such that the sum of the number and four times its square is the least. What is that number?

    1. −0·625
    2. −0·125
    3. 0·125
    4. 1
    Show answer

    Answer: (2) −0·125

    f(x) = 4x² + x is a upward parabola with minimum at x = −b/(2a) = −1/8 = −0·125 (minimum value −1/16).

  2. Q2 · Arithmetic · Number System

    The difference of the square of two natural numbers m and n (m > n) is 72. How many pairs of natural numbers will satisfy?

    1. 3
    2. 4
    3. 5
    4. 6
    Show answer

    Answer: (1) 3

    (m − n)(m + n) = 72 needs both factors of the same parity, i.e. both even: 2×36, 4×18, 6×12. These give (m, n) = (19, 17), (11, 7), (9, 3), so 3 pairs.

  3. Q3 · Arithmetic · Number System

    Let N be a 5-digit number. When N is divided by 6, 12, 15, 24 it leaves respectively 2, 8, 11, 20 as remainders. What is the greatest value of N?

    1. 99960
    2. 99956
    3. 99950
    4. 99946
    Show answer

    Answer: (2) 99956

    In each case divisor − remainder = 4, so N + 4 is a multiple of LCM(6, 12, 15, 24) = 120. The largest 5-digit multiple of 120 is 99960, so N = 99956.

  4. Q4 · Arithmetic · Number System

    What is the remainder when 111²²² + 222³³³ + 333⁴⁴⁴ is divided by 5?

    1. 1
    2. 2
    3. 3
    4. 4
    Show answer

    Answer: (4) 4

    Mod 5: 111 ≡ 1, so 1²²² = 1; 222 ≡ 2 and 2⁴ ≡ 1, 333 = 4·83 + 1 so 2³³³ ≡ 2; 333 ≡ 3 and 444 is a multiple of 4, so 3⁴⁴⁴ ≡ 1. Sum ≡ 1 + 2 + 1 = 4.

  7. Q7 · Arithmetic · Number System

    Let N be the least positive multiple of 11 that leaves a remainder of 5 when divided by 6, 12, 15, 18. Which one of the following is correct?

    1. 900 < N < 1000
    2. 1000 < N < 1100
    3. 1100 < N < 1200
    4. 1200 < N < 1300
    Show answer

    Answer: (4) 1200 < N < 1300

    N = 180k + 5 (LCM of 6, 12, 15, 18 is 180). 180k + 5 ≡ 4k + 5 (mod 11) = 0 first at k = 7, so N = 1265, which lies between 1200 and 1300.

  8. Q8 · Arithmetic · Number System

    What is 1/(√10 + √9) + 1/(√11 + √10) + 1/(√12 + √11) + ... + 1/(√196 + √195) equal to?

    1. 17
    2. 14
    3. 11
    4. 10
    Show answer

    Answer: (3) 11

    Rationalising, 1/(√(k+1) + √k) = √(k+1) − √k, so the sum telescopes to √196 − √9 = 14 − 3 = 11.

  9. Q9 · Arithmetic · Speed & Distance

    Train X crosses a man standing on the platform in 24 seconds and train Y crosses a man standing on the platform in 18 seconds. They cross each other while running in opposite directions in 20 seconds. What is the ratio of speed of X to speed of Y?

    1. 1 : 2
    2. 2 : 3
    3. 1 : 3
    4. 3 : 4
    Show answer

    Answer: (1) 1 : 2

    Lengths are 24x and 18y, so 24x + 18y = 20(x + y), giving 4x = 2y, i.e. x : y = 1 : 2.

  10. Q10 · Algebra · Polynomials & Quadratics

    Let p, q be the roots of the equation x² + mx − n = 0 and m, n be the roots of the equation x² + px − q = 0 (m, n, p, q are non-zero numbers). Which of the following statements is/are correct? I. m(m + n) = −1 II. p + q = 1 Select the answer using the code given below:

    1. I only
    2. II only
    3. Both I and II
    4. Neither I nor II
    Show answer

    Answer: (3) Both I and II

    p + q = −m, pq = −n, m + n = −p, mn = −q. The two sum relations give q = n; then pq = −n gives p = −1 and mn = −n gives m = −1, so q = n = 2. Hence m(m + n) = −1 × 1 = −1 and p + q = 1; both hold.
