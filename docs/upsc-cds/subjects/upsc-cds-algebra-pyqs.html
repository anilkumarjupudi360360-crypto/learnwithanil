Equations & Expressions

  1. CDS II 2023 · Maths · Q1 · Algebra · Equations & Expressions

    If a² − bc = α, b² − ac = β, c² − ab = γ, then what is (aα + bβ + cγ)/((a + b + c)(α + β + γ)) equal to?

    1. a + b − c
    2. a − b + c
    3. −a + b + c
    4. 1
    Show answer

    Answer: (4) 1

    aα + bβ + cγ = a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca), and α + β + γ = a² + b² + c² − ab − bc − ca. So the ratio is exactly 1.

  2. CDS II 2023 · Maths · Q8 · Algebra · Equations & Expressions

    If 2a/3 = 4b/5 = 3c/4, then what is the value of (18/a)√(a² + c² − b²)?

    1. 3√5
    2. √355
    3. √375
    4. 3√15
    Show answer

    Answer: (2) √355

    Set each ratio equal to k: a = 3k/2, b = 5k/4, c = 4k/3. Then a² + c² − b² = k²(81 + 64 − 56.25)/36 = 355k²/144, so (18/a)·(√355·k/12) = (12/k)(√355·k/12) = √355.

Polynomials & Quadratics

  1. CDS II 2023 · Maths · Q2 · Algebra · Polynomials & Quadratics

    If (x − 1)³ is a factor of x⁴ + αx³ + βx² + γx − 1, then the other factor will be:

    1. x + 1
    2. x − 3
    3. x + 2
    4. x
    Show answer

    Answer: (1) x + 1

    The other factor is linear, say (x + k). Comparing constant terms, (−1)³·k = −1, so k = 1. Check: (x − 1)³(x + 1) = x⁴ − 2x³ + 2x − 1.
