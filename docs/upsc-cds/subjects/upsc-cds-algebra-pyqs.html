    If p/q = q/r = r/s = k, then what is (p³ + q³ + r³)/(q³ + r³ + s³) equal to?

    1. p/s
    2. r/q
    3. s/p
    4. q/r
    Show answer

    Answer: (1) p/s

    Each term of the numerator is k times the matching term of the denominator (p = kq, q = kr, r = ks), so the ratio is k³. Also p/s = (p/q)(q/r)(r/s) = k³, so the answer is p/s.

  2. CDS II 2026 · Maths · Q5 · Algebra · Equations & Expressions

    If 1/(2b + 2c) + 1/(2c + 2a) = 1/(a + b), then what is a² + b² + c² equal to?

    1. 9c²
    2. 4c²
    3. 3c²
    4. 2c²
    Show answer

    Answer: (3) 3c²

    Clearing denominators: (a + b)(c + a) + (a + b)(b + c) = 2(b + c)(c + a), i.e. (a + b)² + 2c(a + b) = 2c² + 2ab + 2c(a + b), which gives a² + b² = 2c². Hence a² + b² + c² = 3c².

    If 1/x = 1/p + 1/q, then what is pq/(p² − q²) × ((x + p)/(x − p) − (x + q)/(x − q)) equal to?

    1. −2
    2. −1
    3. 1
    4. 2
    Show answer

    Answer: (4) 2

    x = pq/(p + q), so (x + p)/(x − p) = −(2p + q)/q and (x + q)/(x − q) = −(p + 2q)/p. Their difference is 2(p² − q²)/pq, so the whole expression is 2 (checked with p = 2, q = 3).

    Let x, y, z be variables such that (x + y + z) = k, where k is a constant. If (x + z − y) × (x − z + y) is proportional to yz, then (y + z − x) is proportional to:

    1. x
    2. y
    3. yz
    4. xz
    Show answer

    Answer: (3) yz

    (x + z − y)(x − z + y) = (k − 2y)(k − 2z) = k(k − 2y − 2z) + 4yz = k(x − y − z) + 4yz. If this equals c·yz, then k(y + z − x) = (4 − c)yz, so (y + z − x) is proportional to yz.
