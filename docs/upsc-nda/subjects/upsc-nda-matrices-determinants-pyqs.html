    Let X be a matrix of order 3×3, Y be a matrix of order 2×3 and Z be a matrix of order 3×2. Which of the following statements are correct? I. (ZY)X is defined and is a square matrix of order 3. II. Y(XZ) is defined and is a square matrix of order 2. III. X(YZ) is not defined. Select the answer using the code given below.

    1. I and II only
    2. II and III only
    3. I and III only
    4. I, II and III
    Show answer

  7. NDA II 2024 · Maths · Q5 · Matrices & Determinants · Matrices

    Let A and B be two square matrices of same order. If AB is a null matrix, then which one of the following is correct?

    1. Both A and B are null matrices
    2. Either A or B is a null matrix
    3. B is a null matrix if A is a non-singular matrix
    4. Both A and B are singular matrices
    Show answer

    Answer: (3) B is a null matrix if A is a non-singular matrix

    If A is non-singular, multiply AB = O on the left by A⁻¹ to get B = O. Options (1), (2) fail because two non-zero matrices can have a zero product, and (4) fails when A is invertible and B = O.

  16. NDA II 2023 · Maths · Q8 · Matrices & Determinants · Matrices

    If A = [[0, 3, 4], [−3, 0, 5], [−4, −5, 0]], then which one of the following statements is correct?

    1. A² is symmetric matrix with det(A²) = 0.
    2. A² is symmetric matrix with det(A²) ≠ 0.
    3. A² is skew-symmetric matrix with det(A²) = 0.
    4. A² is skew-symmetric matrix with det(A²) ≠ 0.
    Show answer

    Answer: (1) A² is symmetric matrix with det(A²) = 0.

    A is skew-symmetric (A′ = −A), so (A²)′ = (A′)² = A², which makes A² symmetric. A is skew-symmetric of odd order, so det(A) = 0 and det(A²) = (det A)² = 0.

  19. NDA I 2023 · Maths · Q6 · Matrices & Determinants · Matrices

    Let A and B be symmetric matrices of same order, then which one of the following is correct regarding (AB − BA) ? 1. Its diagonal entries are equal but nonzero 2. The sum of its non-diagonal entries is zero Select the correct answer using the code given below :

    1. 1 only
    2. 2 only
    3. Both 1 and 2
    4. Neither 1 nor 2
    Show answer

    Answer: (2) 2 only

    (AB − BA)ᵀ = BA − AB, so AB − BA is skew-symmetric. Its diagonal entries are all zero, so statement 1 is false. Its off-diagonal entries come in pairs aᵢⱼ = −aⱼᵢ, so they add up to zero.

  20. NDA I 2023 · Maths · Q7 · Matrices & Determinants · Matrices

    Consider the following statements in respect of square matrices A, B, C each of same order n : 1. AB = AC ⇒ B = C if A is non-singular 2. If BX = CX for every column matrix X having n rows then B = C Which of the statements given above is/are correct ?

    2. 2 only
    3. Both 1 and 2
    4. Neither 1 nor 2
    Show answer

    Answer: (3) Both 1 and 2

    If A is non-singular, multiplying AB = AC by A⁻¹ gives B = C. If BX = CX for every X, take X as each unit column vector eⱼ: then every column of B equals the matching column of C, so B = C.

  21. NDA I 2023 · Maths · Q9 · Matrices & Determinants · Matrices

    Let AX = B be a system of 3 linear equations with 3-unknowns. Let X₁ and X₂ be its two distinct solutions. If the combination aX₁ + bX₂ is a solution of AX = B; where a, b are real numbers, then which one of the following is correct ?

    1. a = b
    2. a + b = 1
    3. a + b = 0
    4. a − b = 1
    Show answer

    Answer: (2) a + b = 1

    A(aX₁ + bX₂) = aB + bB = (a + b)B. For this to equal B (with B ≠ 0), we need a + b = 1.

    If Δ = |[a, b, c], [d, e, f], [g, h, i]| and A, B, C, D, G are the cofactors of the elements a, b, c, d, g respectively, then what is bB + cC − dD − gG equal to?

  2. NDA I 2025 · Maths · Q9 · Matrices & Determinants · Determinants

    Consider the following statements in respect of the determinant Δ = |[k(k + 2), 2k + 1, 1], [2k + 1, k + 2, 1], [3, 3, 1]| I. Δ is positive if k > 0. II. Δ is negative if k < 0. III. Δ is zero if k = 0. How many of the statements given above are correct?

    1. None
    2. One
    3. Two
    4. All three
    Show answer

    Answer: (2) One

    Expanding gives Δ = (k − 1)³ (checked in python: k = 0 gives −1, k = 1 gives 0, k = 2 gives 1). So Δ < 0 for all k < 0 (II true), but Δ ≤ 0 for 0 < k ≤ 1 (I false) and Δ = −1 at k = 0 (III false). Only one is correct.

  10. NDA I 2024 · Maths · Q1 · Matrices & Determinants · Determinants

    Let A and B be matrices of order 3×3. If |A| = 1/(2√2) and |B| = 1/729, then what is the value of |2B(adj(3A))| ?

    For order 3, |adj(3A)| = |3A|² = (27|A|)² = (27/(2√2))² = 729/8. Then |2B·adj(3A)| = 2³ × |B| × 729/8 = 8 × (1/729) × (729/8) = 1.

    |3A| = 3³ × 4 = 108, |adj(3A)| = |3A|² = 108² = 2⁴·3⁶, and |2 adj(3A)| = 2³ × 2⁴·3⁶ = 2⁷·3⁶. So α + β = 7 + 6 = 13.

  24. NDA I 2023 · Maths · Q8 · Matrices & Determinants · Determinants

    The system of linear equations x + 2y + z = 4, 2x + 4y + 2z = 8 and 3x + 6y + 3z = 10 has

    1. a unique solution
    2. infinite many solutions
    3. no solution
    4. exactly three solutions
    Show answer

    Answer: (3) no solution

    The first equation gives x + 2y + z = 4, so 3x + 6y + 3z = 12. This contradicts 3x + 6y + 3z = 10, so the system is inconsistent. In rank terms, rank of the coefficient matrix is 1 and rank of the augmented matrix is 2.

  25. NDA I 2023 · Maths · Q10 · Matrices & Determinants · Determinants

    What is the sum of the roots of the equation |[[0, x − a, x − b], [0, 0, x − c], [x + b, x + c, 1]]| = 0 ?

    1. a + b + c
    2. a − b + c
    3. a + b − c
    4. a − b − c
    Show answer

    Answer: (2) a − b + c

    Expand along the first column: the determinant is (x + b)[(x − a)(x − c) − 0] = (x + b)(x − a)(x − c). The roots are −b, a and c, so their sum is a − b + c.
