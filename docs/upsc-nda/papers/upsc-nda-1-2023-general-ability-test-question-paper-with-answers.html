  1. Q1 · English · Spotting Errors

    Find the part of the sentence that has an error; if there is no error, choose (d). Over long periods of time, layers of sediments builds up to a height of a few kilometers.

    1. Over long periods of time,
    2. layers of sediments builds up
    3. to a height of a few kilometers.
    4. No error
    Show answer

    Answer: (2) layers of sediments builds up

    The subject is the plural "layers", so the verb must be plural: "layers of sediments build up". "Builds" wrongly agrees with "sediments"/singular.

  2. Q2 · English · Spotting Errors

    Find the part of the sentence that has an error; if there is no error, choose (d). When a gas is cooled down it turns into a liquid from a process called condensation.

    1. When a gas is
    2. cooled down it turns into a liquid
    3. from a process called condensation.
    4. No error
    Show answer

    Answer: (3) from a process called condensation.

    A change happens "by" or "through" a process, not "from" a process, so part (c) should read "by a process called condensation".
