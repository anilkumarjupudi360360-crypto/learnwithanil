  1. Q1 · Algebra · Sequences & Series

    The sum of the first k terms of a series S is 3k² + 5k. Which one of the following is correct?

    1. The terms of S form an arithmetic progression with common difference 14.
    2. The terms of S form an arithmetic progression with common difference 6.
    3. The terms of S form a geometric progression with common ratio 10/7.
    4. The terms of S form a geometric progression with common ratio 11/4.
    Show answer

    Answer: (2) The terms of S form an arithmetic progression with common difference 6.

    The k-th term is S_k − S_(k−1) = 6k + 2 (and T₁ = 8 = S₁), giving 8, 14, 20, … – an AP with common difference 6.

  3. Q3 · Algebra · Quadratic Equations & Inequalities

    If one root of the equation x² − kx + k = 0 exceeds the other by 2√3, then which one of the following is a value of k?

    1. 3
    2. 6
    3. 9
    4. 12
    Show answer

    Answer: (2) 6

  6. Q6 · Algebra · Sequences & Series

    If p, 1, q are in AP and p, 2, q are in GP, then which of the following statements is/are correct? I. p, 4, q are in HP. II. (1/p), 1/4, (1/q) are in AP. Select the answer using the code given below.

    1. I only
    2. II only
    3. Both I and II
    4. Neither I nor II
    Show answer

    Answer: (3) Both I and II

    p + q = 2 and pq = 4. The HM of p and q is 2pq/(p + q) = 8/2 = 4, so p, 4, q are in HP (I); equivalently 1/p + 1/q = (p + q)/pq = 1/2 = 2 × 1/4, so II holds too.

    If Δ = |[a, b, c], [d, e, f], [g, h, i]| and A, B, C, D, G are the cofactors of the elements a, b, c, d, g respectively, then what is bB + cC − dD − gG equal to?

    Show answer

  9. Q9 · Matrices & Determinants · Determinants

    Consider the following statements in respect of the determinant Δ = |[k(k + 2), 2k + 1, 1], [2k + 1, k + 2, 1], [3, 3, 1]| I. Δ is positive if k > 0. II. Δ is negative if k < 0. III. Δ is zero if k = 0. How many of the statements given above are correct?

    1. None
    2. One
    3. Two
    4. All three
    Show answer

    Answer: (2) One

    Expanding gives Δ = (k − 1)³ (checked in python: k = 0 gives −1, k = 1 gives 0, k = 2 gives 1). So Δ < 0 for all k < 0 (II true), but Δ ≤ 0 for 0 < k ≤ 1 (I false) and Δ = −1 at k = 0 (III false). Only one is correct.
