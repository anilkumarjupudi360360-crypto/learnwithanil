  1. Q1 · Algebra · Sequences & Series

    If pˣ = qʸ = rᶻ, where x, y and z are in GP, then consider the following statements : I. p, q and r are in AP. II. ln p, ln q and ln r are in GP. Which of the statements given above is/are correct?

    1. I only
    2. II only
    3. Both I and II
    4. Neither I nor II
    Show answer

    Answer: (2) II only

    Let pˣ = qʸ = rᶻ = k; then x = ln k/ln p, y = ln k/ln q, z = ln k/ln r. Since x, y, z are in GP, 1/ln p, 1/ln q, 1/ln r are in GP, and hence so are ln p, ln q, ln r (y² = xz gives (ln q)² = ln p·ln r). Nothing forces p, q, r into AP, so only II holds.

  2. Q2 · Algebra · Sets, Relations & Functions

    If A and B are non-empty subsets of a set, and Aᶜ and Bᶜ represent their complements, then which of the following is/are correct? I. A − B = Bᶜ − Aᶜ II. A − Bᶜ = Aᶜ − B Select the answer using the code given below.

    1. I only
    2. II only
    3. Both I and II
    4. Neither I nor II
    Show answer

    Answer: (1) I only

    Bᶜ − Aᶜ = Bᶜ ∩ A = A − B, so I is true. A − Bᶜ = A ∩ B while Aᶜ − B = Aᶜ ∩ Bᶜ, which are different in general, so II is false.

  4. Q4 · Algebra · Permutations & Combinations

    Let n be a natural number. The number of consecutive zeros at the end of the expansion of n! is exactly 2. How many values of n are possible?

    1. 3
    2. 4
    3. 5
    4. More than 5
    Show answer

    Answer: (3) 5

    Trailing zeros of n! = [n/5] + [n/25] + … . This equals exactly 2 for n = 10, 11, 12, 13, 14. At n = 15 it becomes 3. So there are 5 values.

  5. Q5 · Algebra · Sequences & Series

    If (10 + log₁₀ x), (10 + log₁₀ y) and (10 + log₁₀ z) are in AP, then consider the following statements : I. The GM of x and z is y². II. The AM of log₁₀ x and log₁₀ z is log₁₀ y. Which of the statements given above is/are correct?

    2. II only

  7. Q7 · Algebra · Sequences & Series

    How many terms are identical in the two APs 19, 21, 23, … up to 110 terms and 19, 22, 25, 28, … up to 75 terms?

    1. 35
    2. 36
    3. 37
    4. 38
    Show answer

    Answer: (3) 37

    The common terms form an AP 19, 25, 31, … with common difference LCM(2, 3) = 6. The first AP ends at 19 + 109×2 = 237 and the second at 19 + 74×3 = 241. So we need 19 + 6(k − 1) ≤ 237, which gives k ≤ 37 (the last common term is 19 + 6×36 = 235). There are 37 common terms.

  8. Q8 · Algebra · Complex Numbers

    If α = (−1 + √−3)/2 then what is the value of (1 + α¹⁹ − α³⁵)¹⁰⁰ − (1 − 3α²⁵ + α³⁸)⁵⁰?

    1. −2
    2. −1
    3. 0
    4. 2
    Show answer

    Answer: (3) 0

    α = ω, so α¹⁹ = ω, α³⁵ = ω², α²⁵ = ω and α³⁸ = ω². Then 1 + ω − ω² = −2ω², and (−2ω²)¹⁰⁰ = 2¹⁰⁰ω²⁰⁰ = 2¹⁰⁰ω². Also 1 − 3ω + ω² = −4ω, and (−4ω)⁵⁰ = 2¹⁰⁰ω⁵⁰ = 2¹⁰⁰ω². The difference is 0.
