  1. Q1 · Algebra · Complex Numbers

    If ω is a non-real cube root of 1, then what is the value of |(1 − ω)/(ω + ω²)| ?

    1. √3
    2. √2
    3. 1
    4. 4/√3
    Show answer

    Answer: (1) √3

    Since 1 + ω + ω² = 0, ω + ω² = −1, so the denominator has modulus 1. |1 − ω| = |1 − (−1/2 + i√3/2)| = |3/2 − i√3/2| = √(9/4 + 3/4) = √3.

  3. Q4 · Matrices & Determinants · Determinants

    Let A be a matrix of order 3×3 and |A| = 4. If |2 adj(3A)| = 2^α 3^β, then what is the value of (α + β) ?

    1. 12
    2. 13
    3. 17
    4. 24
    Show answer

    Answer: (2) 13

    |3A| = 3³ × 4 = 108, |adj(3A)| = |3A|² = 108² = 2⁴·3⁶, and |2 adj(3A)| = 2³ × 2⁴·3⁶ = 2⁷·3⁶. So α + β = 7 + 6 = 13.

  4. Q5 · Algebra · Complex Numbers

    If α and β are the distinct roots of equation x² − x + 1 = 0, then what is the value of |(α¹⁰⁰ + β¹⁰⁰)/(α¹⁰⁰ − β¹⁰⁰)| ?

    1. √3
    2. √2

    Show answer

  5. Q6 · Matrices & Determinants · Matrices

    Let A and B be symmetric matrices of same order, then which one of the following is correct regarding (AB − BA) ? 1. Its diagonal entries are equal but nonzero 2. The sum of its non-diagonal entries is zero Select the correct answer using the code given below :

    1. 1 only
    2. 2 only
    3. Both 1 and 2
    4. Neither 1 nor 2
    Show answer

    Answer: (2) 2 only

    (AB − BA)ᵀ = BA − AB, so AB − BA is skew-symmetric. Its diagonal entries are all zero, so statement 1 is false. Its off-diagonal entries come in pairs aᵢⱼ = −aⱼᵢ, so they add up to zero.

  6. Q7 · Matrices & Determinants · Matrices

    Consider the following statements in respect of square matrices A, B, C each of same order n : 1. AB = AC ⇒ B = C if A is non-singular 2. If BX = CX for every column matrix X having n rows then B = C Which of the statements given above is/are correct ?

    1. 1 only
    2. 2 only
    3. Both 1 and 2
    4. Neither 1 nor 2
    Show answer

    Answer: (3) Both 1 and 2

    If A is non-singular, multiplying AB = AC by A⁻¹ gives B = C. If BX = CX for every X, take X as each unit column vector eⱼ: then every column of B equals the matching column of C, so B = C.

  7. Q8 · Matrices & Determinants · Determinants

    The system of linear equations x + 2y + z = 4, 2x + 4y + 2z = 8 and 3x + 6y + 3z = 10 has

    1. a unique solution
    2. infinite many solutions
    3. no solution
    4. exactly three solutions
    Show answer

    Answer: (3) no solution

    The first equation gives x + 2y + z = 4, so 3x + 6y + 3z = 12. This contradicts 3x + 6y + 3z = 10, so the system is inconsistent. In rank terms, rank of the coefficient matrix is 1 and rank of the augmented matrix is 2.

  9. Q10 · Matrices & Determinants · Determinants

    What is the sum of the roots of the equation |[[0, x − a, x − b], [0, 0, x − c], [x + b, x + c, 1]]| = 0 ?

    1. a + b + c
    2. a − b + c
    3. a + b − c
    4. a − b − c
    Show answer

    Answer: (2) a − b + c

    Expand along the first column: the determinant is (x + b)[(x − a)(x − c) − 0] = (x + b)(x − a)(x − c). The roots are −b, a and c, so their sum is a − b + c.
