  4. UG CBT-1 · 1 September S1 · Q5 · Computer Knowledge · Computer Basics & Hardware

    Which memory is non-volatile, meaning it retains data even after the computer is turned off?

    1. Virtual Memory
    2. Cache Memory
    3. ROM
    4. RAM

    कौन-सी मेमोरी नॉन-वोलेटाइल है, यानी कंप्यूटर ऑफ होने के बाद भी यह डेटा को बरकरार रखती है?

    1. वर्चुअल मेमोरी (Virtual Memory)
    2. कैश मेमोरी (Cache Memory)
    3. रोम (ROM)
    4. रैम (RAM)
    Show answer

    Answer: (3) ROM

    उत्तर: (3) रोम (ROM)

    ROM (read-only memory) keeps its contents without power; it holds firmware such as the BIOS. RAM and cache lose their data when power is off, and virtual memory is a part of the disk used as an extension of RAM.

    ROM (रीड-ओनली मेमोरी) बिजली के बिना भी अपना डेटा रखती है; इसमें BIOS जैसा फ़र्मवेयर रहता है। RAM और कैश बिजली बंद होने पर डेटा खो देती हैं, और वर्चुअल मेमोरी डिस्क का वह भाग है जो RAM के विस्तार की तरह काम करता है।
