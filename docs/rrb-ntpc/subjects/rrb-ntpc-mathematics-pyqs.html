    Three positive integers, A, B, and C, satisfy the following conditions: HCF(A,B) = 12, HCF(B,C) = 18, HCF(A,C) = 6 and LCM(A,B,C) = 1080. If A = 12x, B = 36y, and C = 18z, where x, y, and z are pairwise coprime positive integers, then the minimum possible value of A + B + C is:

    1. 222
    2. 216
    3. 224
    4. 220

    तीन धनात्मक पूर्णांकों A, B और C द्वारा HCF(A,B) = 12, HCF(B,C) = 18, HCF(A,C) = 6 और LCM(A,B,C) = 1080 शर्तों को संतुष्ट किया जाता है। यदि A = 12x, B = 36y और C = 18z, जहाँ x, y और z युग्मानूसार सहअभाज्य धनात्मक पूर्णांक हैं, तो A + B + C का न्यूनतम संभव मान कितना है?

    1. 222
    2. 216
    3. 224
    4. 220
    Show answer

    Answer: (1) 222

    1080 = 2³ × 3³ × 5, and A, B, C must between them supply 2³, 3³ and 5. Taking x = 2, y = 3, z = 5 gives A = 24, B = 108, C = 90. Check: HCF(24, 108) = 12, HCF(108, 90) = 18, HCF(24, 90) = 6 and LCM = 1080. The sum is 24 + 108 + 90 = 222; other valid choices (such as 12, 216, 90 or 60, 216, 18) give larger sums.

    1080 = 2³ × 3³ × 5, और A, B, C मिलकर 2³, 3³ और 5 देने चाहिए। x = 2, y = 3, z = 5 लेने पर A = 24, B = 108, C = 90। जाँच: HCF(24, 108) = 12, HCF(108, 90) = 18, HCF(24, 90) = 6 और LCM = 1080। योग 24 + 108 + 90 = 222; अन्य मान्य विकल्प (जैसे 12, 216, 90 या 60, 216, 18) बड़ा योग देते हैं।
