  2. Q2 · General Science · Biology

    Which of the following is the correct terminology for the gap between two neurons where they communicate?

    1. Node gap
    2. Synaptic cleft
    3. Dendritic cleft
    4. Axonal gap

    दो न्यूरॉन्स के बीच के अंतराल, जहाँ वे संप्रेषण करते हैं, के लिए निम्नलिखित में से कौन-सी शब्दावली सही है?

    1. नोड अंतराल (Node gap)
    2. अंतर्ग्रथित विदर (Synaptic cleft)
    3. द्रुमाकृतिक विदर (Dendritic cleft)
    4. तंत्रिकाक्षीय अंतराल (Axonal gap)
    Show answer

    Answer: (2) Synaptic cleft

    उत्तर: (2) अंतर्ग्रथित विदर (Synaptic cleft)

    A synapse is the junction between two neurons; the tiny gap across it is the synaptic cleft. A nerve impulse crosses it as chemical neurotransmitters released by the first neuron.

    दो न्यूरॉनों का जोड़ सिनैप्स कहलाता है और उसके बीच का सूक्ष्म अंतराल सिनैप्टिक दरार (synaptic cleft)। तंत्रिका आवेग इसे पहले न्यूरॉन से निकले रासायनिक न्यूरोट्रांसमीटर के रूप में पार करता है।

  5. Q5 · Computer Knowledge · Computer Basics & Hardware

    Which memory is non-volatile, meaning it retains data even after the computer is turned off?

    1. Virtual Memory
    2. Cache Memory
    3. ROM
    4. RAM

    कौन-सी मेमोरी नॉन-वोलेटाइल है, यानी कंप्यूटर ऑफ होने के बाद भी यह डेटा को बरकरार रखती है?

    1. वर्चुअल मेमोरी (Virtual Memory)
    2. कैश मेमोरी (Cache Memory)
    3. रोम (ROM)
    4. रैम (RAM)
    Show answer

    Answer: (3) ROM

    उत्तर: (3) रोम (ROM)

    ROM (read-only memory) keeps its contents without power; it holds firmware such as the BIOS. RAM and cache lose their data when power is off, and virtual memory is a part of the disk used as an extension of RAM.

    ROM (रीड-ओनली मेमोरी) बिजली के बिना भी अपना डेटा रखती है; इसमें BIOS जैसा फ़र्मवेयर रहता है। RAM और कैश बिजली बंद होने पर डेटा खो देती हैं, और वर्चुअल मेमोरी डिस्क का वह भाग है जो RAM के विस्तार की तरह काम करता है।
