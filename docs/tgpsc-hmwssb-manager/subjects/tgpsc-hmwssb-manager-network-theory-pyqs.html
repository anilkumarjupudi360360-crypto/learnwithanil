Network Laws & Theorems

  1. Manager 2015 Paper 2 (ECE) · Q2 · Network Theory · Network Laws & Theorems

    The voltage across 5 A source in the given circuit is

    1. 17.5 volt
    2. 25 volt
    3. 15 volt
    4. 20 volt
    Show answer

    Answer: (1) 17.5 volt

    Take the bottom wire as reference and let V be the top-right node (the node shared by the shunt 5 Ω and the 5 A source). KCL at that node: (V − 10)/5 + V/5 = 5 → 2V − 10 = 25 → V = 17.5 V, which is the voltage across the 5 A source.

  2. Manager 2015 Paper 2 (ECE) · Q4 · Network Theory · Network Laws & Theorems

    An ideal voltage source and current sources are connected in parallel. This circuit has

    1. neither Thevenin nor Norton's equivalent
    2. both Thevinin and Norton's equivalent
    3. a Thevenin equivalent but not Norton's equivalent
    4. a Norton's equivalent but not Thevenin equivalent
    Show answer

    Answer: (3) a Thevenin equivalent but not Norton's equivalent

    An ideal voltage source fixes the terminal voltage whatever current sources are in parallel with it, so the combination is just that voltage source: a Thevenin equivalent with V_th = V and R_th = 0. A Norton equivalent would need I_N = V_th/R_th = V/0, which is infinite, so it does not exist.

AC Circuits & Resonance

  1. Manager 2015 Paper 2 (ECE) · Q1 · Network Theory · AC Circuits & Resonance

    A capacitor C is connected across a coil with resistance R and inductance L. The effective [impedance] of the circuit at resonance is

    1. 1/(RLC)
    2. RC/L
    3. L/(RC)
    4. L/√(RC)
    Show answer

    Answer: (3) L/(RC)

    For a coil (R in series with L) in parallel with C, the admittance at resonance is purely real: Y = R/(R² + ω₀²L²), and the resonance condition gives R² + ω₀²L² = L/C. So the effective (dynamic) impedance is Z = 1/Y = (L/C)/R = L/(RC), a pure resistance that is large when R is small. (The booklet leaves out the word "impedance"; it is added in square brackets.)

  2. Manager 2015 Paper 2 (ECE) · Q3 · Network Theory · AC Circuits & Resonance

    The current i(t) through a 10Ω resistor in series with an inductance is given by i(t) = 3 + 4 sin(100t + 45°) + 4sin(300t + 60°) Amperes. The rms value of the current and the power dissipated in the circuit are

    1. 40 A, 410W
    2. 10A, 350W
    3. 5A, 250W
    4. 11A, 250W
    Show answer

    Answer: (3) 5A, 250W

    For a sum of a dc term and sinusoids of different frequencies, I_rms = √(I_dc² + I₁²/2 + I₂²/2) = √(9 + 8 + 8) = √25 = 5 A. Only the resistor dissipates power (the inductance stores energy), so P = I_rms²R = 25 × 10 = 250 W.

Transients & Laplace Analysis

  1. Manager 2015 Paper 2 (ECE) · Q5 · Network Theory · Transients & Laplace Analysis

    A transient current in a network is i(t) = 2e⁻ᵗ − e⁻⁵ᵗ, t ≥ 0. The pole-zero configuration of I(s) is

    1. poles : 1,5 zeros : 9
    2. poles : −1, −5 zeros : −9
    3. poles : 2, −1 zeros : −1, −5
    4. poles : 2, −1 zeros: 1, 5
    Show answer

    Answer: (2) poles : −1, −5 zeros : −9

    I(s) = 2/(s + 1) − 1/(s + 5) = (2s + 10 − s − 1)/((s + 1)(s + 5)) = (s + 9)/((s + 1)(s + 5)). So the poles are at s = −1 and −5 and the zero is at s = −9.

  2. Manager 2015 Paper 2 (ECE) · Q7 · Network Theory · Transients & Laplace Analysis

    The transfer function of a system Z(s) = V(s)/I(s)= s/(s+3). The system is at rest for t < 0. What will be the value of v(t) for t ≥ 0, if i(t) = 3 u(t), where u(t) is a step function

    1. e⁻ᵗ
    2. 4 e⁻ᵗ
    3. 2 e⁻³ᵗ
    4. 3e⁻³ᵗ
    Show answer

    Answer: (4) 3e⁻³ᵗ

    I(s) = 3/s, so V(s) = Z(s)I(s) = (s/(s + 3)) × (3/s) = 3/(s + 3). Taking the inverse Laplace transform, v(t) = 3e⁻³ᵗ for t ≥ 0.

Two-Port Networks & Network Synthesis

  1. Manager 2015 Paper 2 (ECE) · Q6 · Network Theory · Two-Port Networks & Network Synthesis

    F(s) = (s+1)(s+3)/(s(s+2)) represents an

    1. RC impedance and an RL admittance
    2. RL admittance
    3. RC impedance
    4. RC admittance
    Show answer

    Answer: (1) RC impedance and an RL admittance

    The poles (0, −2) and zeros (−1, −3) are simple, lie on the negative real axis and alternate, with a pole nearest the origin, and F(0) = ∞ > F(∞) = 1: these are the properties of an RC driving-point impedance, which are exactly those of an RL driving-point admittance. Expanding, F(s) = 1 + 1.5/s + 0.5/(s + 2): as an impedance this is 1 Ω in series with a 2/3 F capacitor and a parallel 2 F, 0.25 Ω section; as an admittance it is 1 S in parallel with a 2/3 H inductor and a branch of 2 H in series with 4 Ω. So it represents both.
