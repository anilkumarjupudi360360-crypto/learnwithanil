Transistor Amplifiers & Biasing

  1. Manager 2015 Paper 2 (ECE) · Q10 · Analog Circuits · Transistor Amplifiers & Biasing

    In a transistor h_fe =50, h_ie=830Ω, h_oe=10⁻⁴ mho. Its output resistance when used in CB configuration is about

    1. 2 MΩ
    2. 2.5 MΩ
    3. 500Ω
    4. 500 KΩ
    Show answer

    Answer: (4) 500 KΩ

    The common-base output admittance is h_ob = h_oe/(1 + h_fe) = 10⁻⁴/51 ≈ 1.96 × 10⁻⁶ mho. So the CB output resistance is 1/h_ob = 51/10⁻⁴ = 510 kΩ, i.e. about 500 kΩ, much higher than the CE value 1/h_oe = 10 kΩ.
