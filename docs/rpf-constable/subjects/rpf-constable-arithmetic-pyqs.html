    1. 537
    2. 529
    3. 547
    4. 543

    वह सबसे छोटी संख्या ज्ञात कीजिए जिसे 36, 45 और 54 से विभाजित करने पर प्रत्येक स्थिति में शेषफल 3 प्राप्त हो।

    1. 537
    2. 529
    3. 547
    4. 543
    Show answer

    Answer: (4) 543

    The required number = LCM(36, 45, 54) + 3. Since 36 = 2² × 3², 45 = 3² × 5 and 54 = 2 × 3³, LCM = 2² × 3³ × 5 = 540. Number = 540 + 3 = 543.

    अभीष्ट संख्या = ल.स.प.(36, 45, 54) + 3। चूँकि 36 = 2² × 3², 45 = 3² × 5 और 54 = 2 × 3³, अतः ल.स.प. = 2² × 3³ × 5 = 540। संख्या = 540 + 3 = 543।

    1. 76/11
    2. 89/9

    Show answer

    Answer: (3) 80/9

    Ashlesha's one-day work = (Isha + Smriti + Ashlesha) − (Isha + Smriti) = 1/8 − 1/16 = 1/16. Isha + Ashlesha = 1/20 + 1/16 = (4 + 5)/80 = 9/80 of the work per day. So they need 80/9 days (8 8/9 days).

    अश्लेषा का एक दिन का कार्य = (ईशा + स्मृति + अश्लेषा) − (ईशा + स्मृति) = 1/8 − 1/16 = 1/16। ईशा + अश्लेषा का एक दिन का कार्य = 1/20 + 1/16 = (4 + 5)/80 = 9/80। अतः उन्हें 80/9 दिन (8 8/9 दिन) लगेंगे।
