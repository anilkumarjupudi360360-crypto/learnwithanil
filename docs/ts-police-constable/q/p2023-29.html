  1. PC Mains 2023 · Q29 · Arithmetic · Ratio, Average & Ages

    If a : b = 3 : 4, b : c = 4 : 5, a + 2b = 55 and 3b − c = 35 then 3a + 2b − c =

    1. 60
    2. 45
    3. 50
    4. 75

    ఒకవేళ a : b = 3 : 4, b : c = 4 : 5, a + 2b = 55 మరియు 3b − c = 35 అయితే 3a + 2b − c =

    1. 60
    2. 45
    3. 50
    4. 75
    Show answer

    Answer: (1) 60

    సమాధానం: (1) 60

    Since b is 4 in both ratios, a : b : c = 3 : 4 : 5; let a = 3k, b = 4k, c = 5k. Then a + 2b = 11k = 55 gives k = 5, so a = 15, b = 20, c = 25 (check: 3b − c = 60 − 25 = 35), and 3a + 2b − c = 45 + 40 − 25 = 60.

    రెండు నిష్పత్తులలోనూ b విలువ 4 కాబట్టి a : b : c = 3 : 4 : 5; a = 3k, b = 4k, c = 5k అనుకుందాం. అప్పుడు a + 2b = 11k = 55 నుండి k = 5, కాబట్టి a = 15, b = 20, c = 25 (సరిచూడటం: 3b − c = 60 − 25 = 35), మరియు 3a + 2b − c = 45 + 40 − 25 = 60.
