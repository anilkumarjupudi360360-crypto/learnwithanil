    If a + b = 1 and a² + b² = 2, then a⁵ + b⁵ =

    1. 21/4

    3. 17/4
    4. 5/2

    1. 21/4

    3. 17/4
    4. 5/2
    Show answer

    Answer: (2) 19/4

    సమాధానం: (2) 19/4

    From a + b = 1 and a² + b² = 2, 2ab = 1 − 2 = −1, so ab = −1/2. Then a³ + b³ = (a + b)³ − 3ab(a + b) = 1 + 3/2 = 5/2, and a⁵ + b⁵ = (a² + b²)(a³ + b³) − a²b²(a + b) = 2 × 5/2 − 1/4 = 19/4.

    a + b = 1, a² + b² = 2 నుండి 2ab = 1 − 2 = −1, కాబట్టి ab = −1/2. అప్పుడు a³ + b³ = (a + b)³ − 3ab(a + b) = 1 + 3/2 = 5/2, మరియు a⁵ + b⁵ = (a² + b²)(a³ + b³) − a²b²(a + b) = 2 × 5/2 − 1/4 = 19/4.
