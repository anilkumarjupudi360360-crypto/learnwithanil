Q 2 | sci | Biology

(2) Synaptic cleft

~ A synapse is the junction between two neurons; the tiny gap across it is the synaptic cleft. A nerve impulse crosses it as chemical neurotransmitters released by the first neuron.

Q 5 | comp | Computer Basics & Hardware
Which memory is non-volatile, meaning it retains data even after the computer is turned off?
(1) Virtual Memory
(2) Cache Memory
(3) ROM
(4) RAM
= 3
~ ROM (read-only memory) keeps its contents without power; it holds firmware such as the BIOS. RAM and cache lose their data when power is off, and virtual memory is a part of the disk used as an extension of RAM.

Q 44 | qa | Trigonometry & Heights
If cot²θ = 1/(1 − a²), |a| < 1, and θ is an acute angle, then find the value of (secθ + cosecθ tan³θ).

(2) (4 − a²)
(3) (a² − 8)
