Q 1 | qa | Data Interpretation & Sufficiency
Each item in this section contains a question followed by two statements. Answer each item using the following instructions.
Question: X receives three coins of different denominations : 1, 2, 5, 10 and 20. If the total amount received by X is m, does X receive a coin of denomination 5?
Statement I: m is not a prime number.
Statement II: The sum of the digits of m is greater than 5.
(1) Select this option if the question can be answered using one of these statements alone, but cannot be answered using other statement
(2) Select this option if the question can be answered using either statement alone
(3) Select this option if the question can be answered using both the statements together, but cannot be answered using either statement alone
(4) Select this option if the question cannot be answered even using any of the statements
= 1
~ The ten possible three-coin totals are 8, 13, 16, 17, 23, 26, 27, 31, 32 and 35; those that include the 5-coin are 8, 16, 17, 26, 27, 35, and those without it are 13, 23, 31, 32. Statement I (m not prime) leaves 8, 16, 26, 27, 35 (with a 5) and also 32 = 2 + 10 + 20 (without a 5), so it cannot decide. Statement II (digit sum greater than 5) leaves 8, 16, 17, 26, 27, 35, every one of which contains the 5-coin, while 13, 23, 31 and 32 have digit sums of only 4 or 5. So Statement II alone answers "yes" but Statement I alone does not: option (a).

Q 2 | qa | Data Interpretation & Sufficiency
Each item in this section contains a question followed by two statements. Answer each item using the following instructions.
Question: For two distinct real numbers x and y, which of them is bigger?
Statement I: x² < y < 1
Statement II: y < √x < 1
(1) Select this option if the question can be answered using one of these statements alone, but cannot be answered using other statement
(2) Select this option if the question can be answered using either statement alone
(3) Select this option if the question can be answered using both the statements together, but cannot be answered using either statement alone
(4) Select this option if the question cannot be answered even using any of the statements
= 4
~ Statement I: with y = 0.3, x = 0.5 satisfies x² < y (then x > y) and so does x = 0.1 or x = −0.5 (then y > x); not sufficient. Statement II: y < √x < 1 means 0 ≤ x < 1; with x = 0.25 (√x = 0.5), y = 0.4 gives y > x while y = 0.1 gives y < x; not sufficient. Together: x² < y < √x. For 0 < x < 1, x itself lies between x² and √x, so y can fall on either side of x; for x = 0.25 the allowed range 0.0625 < y < 0.5 contains both y = 0.1 (smaller than x) and y = 0.4 (bigger than x). Even both statements cannot decide: option (d).

Q 3 | qa | Data Interpretation & Sufficiency
Each item in this section contains a question followed by two statements. Answer each item using the following instructions.
Question: If x and y are integers, then is x even?
Statement I: x²y² is even.
Statement II: 1 + x² + y² is odd.
(1) Select this option if the question can be answered using one of these statements alone, but cannot be answered using other statement
(2) Select this option if the question can be answered using either statement alone
(3) Select this option if the question can be answered using both the statements together, but cannot be answered using either statement alone
(4) Select this option if the question cannot be answered even using any of the statements
= 3
~ Statement I: x²y² even means xy is even, so at least one of x, y is even; x = 1, y = 2 (x odd) and x = 2, y = 1 (x even) both fit, so it is not sufficient. Statement II: 1 + x² + y² odd means x² + y² is even, so x and y have the same parity; x = y = 1 and x = y = 2 both fit, so it is not sufficient. Together: x and y have the same parity and at least one of them is even, so both are even and x is even. Both statements are needed together: option (c).

Q 4 | qa | Data Interpretation & Sufficiency
Each item in this section contains a question followed by two statements. Answer each item using the following instructions.
Question: X is a collection of certain odd numbers whereas Y is a collection of certain even numbers. T consists of the numbers all of which are either from X or from Y. Is every number of T from Y?
Statement I: The sum of any two numbers belonging to T is even.
Statement II: If both p and q are picked from T, then (p − 1)q is even.
(1) Select this option if the question can be answered using one of these statements alone, but cannot be answered using other statement
(2) Select this option if the question can be answered using either statement alone
(3) Select this option if the question can be answered using both the statements together, but cannot be answered using either statement alone
(4) Select this option if the question cannot be answered even using any of the statements
= 4
~ T contains only odd numbers (from X) and/or even numbers (from Y). Statement I: the sum of any two members is even only if all members have the same parity, so T may be all odd or all even; not sufficient. Statement II: if p is odd, p − 1 is even and (p − 1)q is always even; if some p in T is even, every q must be even. So again T is either all odd or all even; not sufficient. Together the two statements say the same thing, and both T = {1, 3} and T = {2, 4} satisfy them, so whether every number of T comes from Y cannot be decided even with both: option (d).

Q 5 | qa | Data Interpretation & Sufficiency

Question: If x, y and z are integers, each greater than 1, then is x a prime number?
Statement I: xy² = 116
Statement II: xz = 261
(1) Select this option if the question can be answered using one of these statements alone, but cannot be answered using other statement
(2) Select this option if the question can be answered using either statement alone
(3) Select this option if the question can be answered using both the statements together, but cannot be answered using either statement alone
(4) Select this option if the question cannot be answered even using any of the statements
= 1
~ Statement I: 116 = 2² × 29. Since y > 1 and y² must divide 116, the only choice is y = 2, giving x = 29, which is prime; so Statement I alone answers "yes". Statement II: 261 = 3² × 29, and with x, z > 1 the value of x can be 3, 9, 29 or 87; x may be prime (3, 29) or composite (9, 87), so Statement II alone is not sufficient. Q 8 | qa | Algebra
The weight of X, in kg, is denoted by X. The weights of A, B, C, D, P, Q, R and S are measured. Given :
A + B + C + D = 17
A + C = 6
P + Q + S + D = 15
P + Q + R + B = 17
P = R and Q = S
Which one of the following statements is correct?
(1) B and D together weigh less than the total weight of P and Q.
(2) P and Q together weigh more than the total weight of A and C.
(3) P weighs more than Q.
(4) Q weighs more than P.
= 2
~ From A + B + C + D = 17 and A + C = 6, B + D = 11. Using R = P and S = Q, the third and fourth equations become P + 2Q + D = 15 and 2P + Q + B = 17. Adding them: 3(P + Q) + (B + D) = 32, so 3(P + Q) = 21 and P + Q = 7. Hence P and Q together (7 kg) weigh more than A and C (6 kg), so (b) is correct. (a) is false because B + D = 11 is more than 7. Subtracting the two equations gives P − Q = 2 − (B − D), which depends on the unknown split of B and D, so neither (c) nor (d) can be concluded.

Q 9 | qa | Permutations, Combinations & Probability
How many words can one form by shuffling the letters of the word QUEUE, if Q is always followed by U? The words thus formed need not necessarily have any meaning.
(1) 6
(2) 8
(3) 10
(4) 12
= 4
~ QUEUE has the letters Q, U, U, E, E. If Q must be immediately followed by U, tie them into one block "QU"; the items to arrange are then [QU], U, E and E. Number of arrangements = 4!/2! = 24/2 = 12, dividing by 2! for the two identical E’s. Check: the block QU can start at place 1, 2, 3 or 4, and each time the other three letters U, E, E can be arranged in 3!/2! = 3 ways, so 4 × 3 = 12.

Q 10 | qa | Number System
X, Y and Z jump forward 4′, 6′ and 5′, respectively. At 8 AM, they all land on mark 199′. How many times will they all land on the same mark (need not be at the same moment) between mark 195′ and 1000′, if all of them cross mark 1000′ by 9 AM?
(1) 11
(2) 12
(3) 13
(4) 14
= 4
~ X lands on marks 199 + 4k, Y on 199 + 6k and Z on 199 + 5k, so a mark common to all three is 199 + 60k, since LCM(4, 6, 5) = 60. Between 195′ and 1000′ these marks are 199, 259, 319, …, 979 (199 + 60 × 13 = 979; the next, 1039, lies beyond 1000′ and the previous, 139, lies below 195′). So k = 0 to 13 gives 14 common marks. They need not land at the same moment, and since all three pass 1000′ by 9 AM, each of these marks is actually reached by all of them.

Q 13 | qa | Algebra
A toy T jumps forward or backward. In each forward jump, it moves 5′ forward whereas in each backward jump, it moves 2′ backward. If in 31 jumps, T moves exactly 15′ forward, then what is the difference of the number of forward and backward jumps?
(1) 6
(2) 7
(3) 8
(4) 9
= 4
~ Let f be the number of forward jumps and b the number of backward jumps. Then f + b = 31 and 5f − 2b = 15. Substituting b = 31 − f: 5f − 62 + 2f = 15, so 7f = 77, giving f = 11 and b = 20. Check: 5 × 11 − 2 × 20 = 55 − 40 = 15′ forward. The difference between the numbers of forward and backward jumps is 20 − 11 = 9.

Q 14 | lr | Puzzles & Arrangements
Eight persons P, Q, R, S, T, U, V and W sit around a round table in eight different seats placed with equal distance between any two consecutive seats. Both P and R are adjacent to Q. Both T and R are adjacent to S. Both U and W are adjacent to V. S and W are on opposite chairs. If while going in the clockwise direction around the table from P, one meets R before T, then how many persons shall Q cross while moving in the clockwise direction around the table before meeting W?
(1) 5
(2) 4
(3) 2
(4) 1
= 1
~ Q sits between P and R, and S sits between R and T, so P, Q, R, S, T occupy five consecutive seats; V sits between U and W in the remaining three seats. S and W must be opposite (four seats apart), which fixes the order P, Q, R, S, T, U, V, W around the table, with W next to P. Going clockwise from P one meets R before T, so this order runs clockwise (the other direction would reach T first). Moving clockwise from Q, it passes R, S, T, U and V before reaching W: 5 persons. No other seating satisfies all the conditions.

Q 15 | lr | Analytical Reasoning
The top of a table is rectangular and its dimensions are 6′ × 10′. Two rectangular portions of the table top are painted in blue colour; both these portions have dimensions 2.5′ × 8′ and each of them has exactly two sides common with two edges of the table top. If the table is fixed to the ground and the remaining portion of the table top is painted in white, how many different patterns are possible when observed from above?
(1) 2
(2) 4
(3) 6
(4) 8
= 2
~ An 8′ side cannot fit along the 6′ edge, so each 2.5′ × 8′ blue portion lies with its 8′ side along a 10′ edge; to share exactly two sides with the edges of the table top it must sit in a corner, giving 4 possible positions. Two portions in the corners at both ends of the same 10′ edge would overlap (8 + 8 > 10) and merge into one strip, so the two separate portions lie along opposite 10′ edges: both at the left end, both at the right end, or in either of the two diagonal pairs of corners. Because the table is fixed, these are seen as different from above, giving 4 patterns.

Q 18 | lr | Series & Patterns
A pattern formed by two characters a and b is repeated more than once in the following string :
×b×a×a××a×a×bab
What is × × in the 7th and 8th positions from the left in the above string?
(1) aa
(2) ab
(3) ba
(4) bb
= 4
~ The string has 15 places: × b × a × a × × a × a × b a b. Testing pattern lengths, only length 5 fits every given letter: length 1 fails (both a and b occur), length 3 fails because places 4 and 13 would need the same letter but show a and b, and lengths 2, 4, 6 and 7 clash in the same way. With length 5, places 1, 6, 11 give a; places 2, 7, 12 give b; places 3, 8, 13 give b; places 4, 9, 14 give a; places 5, 10, 15 give b. So the pattern is abbab and the string is abbab abbab abbab. Places 7 and 8 are the 2nd and 3rd letters of the pattern: bb.

Q 19 | qa | Number System
If 10ᵐ × 1000 × n = 75²⁵ × 25³² × 32⁷⁵, where n is not divisible by 10, then the value of m is
(1) 101
(2) 111
(3) 121
(4) 131
= 2
~ Write the right side in prime factors: 75²⁵ = 3²⁵ × 5⁵⁰, 25³² = 5⁶⁴ and 32⁷⁵ = 2³⁷⁵, so the product is 2³⁷⁵ × 3²⁵ × 5¹¹⁴. The number of factors of 10 is limited by the power of 5, so the product is exactly 10¹¹⁴ × (2²⁶¹ × 3²⁵), and n = 2²⁶¹ × 3²⁵ has no factor 5, so it is not divisible by 10. Then 10ᵐ × 10³ = 10¹¹⁴ gives m + 3 = 114, so m = 111.

Q 20 | qa | Arithmetic
The speed of a train T is 100 km per hour and the speed of a person P is 4 km per hour. T crosses P in 15 seconds, if P travels along the direction of motion of T. If P travels along the opposite direction of T, then in how much time does T cross P, in seconds, approximately?
(1) 13.51
(2) 13.65
(3) 13.85
(4) 14.05
= 3
~ When P walks in the train’s direction, the relative speed is 100 − 4 = 96 km/h, so the length of the train = 96 × (1000/3600) × 15 = 400 m. When P walks in the opposite direction, the relative speed is 100 + 4 = 104 km/h = 104000/3600 m/s, so the time = 400 × 3600/104000 = 13.846 s, which is about 13.85 seconds. Quick check: the time scales inversely with relative speed, and 15 × 96/104 = 13.85.

Q 21 | qa | Algebra
For 1/3 < x < y < 2, which of the following statements is/are always correct?
I. x + 1/x < y + 1/y
II. √(1 + y²)/y < √(1 + x²)/x
Select the answer using the code given below.
(1) I only
(2) II only
(3) Both I and II
(4) Neither I nor II
= 2
~ Statement I: f(t) = t + 1/t falls on (0, 1) and rises after t = 1, so it is not increasing on (1/3, 2). Counter-example: x = 1/2, y = 1 gives x + 1/x = 2.5 but y + 1/y = 2, so I is not always true. Statement II: √(1 + t²)/t = √(1/t² + 1), and 1/t² decreases as t increases (t > 0), so this expression strictly decreases with t. Hence for x < y its value at y is always smaller than at x, and II always holds. Check: x = 1/2, y = 1 gives √2 ≈ 1.414 < √5 ≈ 2.236. So only II is always correct.
Q 22 | qa | Arithmetic
What is the minimum number of times one needs to measure to get 298 litres of water from a tank, if the measuring cylinders have capacities 1 litre, 6 litres, 25 litres and 100 litres?
(1) 4
(2) 5
(3) 9
(4) 13
= 2
~ The keyed answer counts every use of a cylinder as one measurement, whether it draws water from the tank or pours some back. Draw 100 litres three times (300 litres) and pour back 1 litre twice: 300 − 1 − 1 = 298, so 5 measurements. Four are not enough: two 100s plus two other measures give at most 250 litres, so three 100s are needed, and the fourth measure would then have to remove exactly 2 litres, which no cylinder does. If water could only be drawn out, the least would be 12 (100 × 2 + 25 × 2 + 6 × 8), which is not offered, and 13 (100, 100, 25, 25, 25, 6, 6, 6 and five 1s) is not the minimum even on that reading; so only 5 fits the options.
Q 23 | qa | Permutations, Combinations & Probability
There are four types of weights, namely 1 kg, 2 kg, 5 kg and 10 kg. What is the maximum number of different ways one can measure 20 kg, if at least eight but not more than eleven weights of 1 kg are to be used while measuring?
(1) 7
(2) 8
(3) 9
(4) 10
= 2
~ Let k = number of 1 kg weights (8 to 11); the rest, 20 − k, must come from 2, 5 and 10 kg weights. k = 8: 12 = 2 × 6, or 2 + 5 × 2, or 2 + 10, giving 3 ways. k = 9: 11 = 2 × 3 + 5, 1 way (11 needs an odd 5 kg part). k = 10: 10 = 2 × 5, or 5 × 2, or 10, giving 3 ways. k = 11: 9 = 2 × 2 + 5, 1 way. Total = 3 + 1 + 3 + 1 = 8 different ways. Overlooking the single 10 kg weight as a choice for k = 8 or k = 10 gives too few ways (such as 7).
Q 24 | qa | Geometry & Mensuration
A cut on a solid object divides the object into two parts where the new surfaces thus produced are plane. On the other hand, one single cut can be used to cut more than one object at a time. In an experiment, the total number of pieces produced by applying n cuts is denoted by xₙ. The experiment is performed on a solid cube where pieces remain unmoved after each cut. In this experiment, if after the third cut, the pieces are identical, then which of the following is not a possible value for x₄?
(1) 16
(2) 12
(3) 8
(4) 5
= 1
~ With the pieces unmoved, three cuts give identical pieces in arrangements such as 4 equal slabs (three parallel cuts), 6 equal blocks (one cut one way, two parallel cuts across it) or 8 equal cubes (three mutually perpendicular central cuts). A fourth plane cut can then give 5 (another parallel cut, splitting one of the 4 slabs), 8 (a perpendicular cut through the 4 slabs) or 12 (a cut turning the 3 × 2 arrangement into 3 × 2 × 2). But 16 is impossible: n plane cuts can produce at most (n³ + 5n + 6)/6 pieces, which is 15 for n = 4. Even from the 2 × 2 × 2 state a single plane can pass through at most 7 of the 8 small cubes, giving at most 8 + 7 = 15.
Q 25 | qa | Arithmetic
The class average x in a test increases by 4 when the score of a student is rectified, whose corrected score is 100 instead of 0. Later, the score of another student was found to have been recorded as 81 in place of 56. If there are no other corrections and the final corrected average is y, then y − x is
(1) 2
(2) 3
(3) 5
(4) 6
= 2
~ Let there be n students. Raising one score from 0 to 100 adds 100 to the total and raises the average by 4, so 100/n = 4 and n = 25. The second correction changes 81 to 56, lowering the total by 25, so the average falls by 25/25 = 1. Hence y = x + 4 − 1 and y − x = 3. Check: net change in total = +100 − 25 = +75, and 75/25 = 3. Taking only the first correction gives 4 (not offered), and adding instead of subtracting the second change gives 5.

If X is incorrect, then so is Z; if Y is incorrect, then W is correct; if W is correct, then X is incorrect.

(3) Both I and II
(4) Neither I nor II

Q 37 | qa | Arithmetic

On the other hand, X continued to run with the same speed. They stopped running when X completed exactly 21 rounds. How many times did X and Y meet after they had started and before they finally stopped?
(1) 35
(2) 34
(3) 31
(4) 29
= 1
~ Let T be the time in which X runs 7 rounds and Y runs 5. Phase 1 (0 to T, same direction): X gains 7 − 5 = 2 rounds, so they meet twice, at T/2 and at T (both at the start point when Y turns). Phase 2 (T to 3T, as X needs 2T more for the remaining 14 rounds): X runs 14 rounds and Y, at double speed in the opposite direction, 20 rounds; running towards each other they together cover 14 + 20 = 34 rounds, so they meet 34 times. The 34th of these meetings is at exactly 3T, the instant they stop (both are then at the start point), so it is not "before they finally stopped". Meetings = 2 + 33 = 35. Counting the meeting at the stopping instant would give 36, which is not an option.

Q 78 | qa | Arithmetic
Three partners A, B and C entered into a business. A invested one-third of the capital for one-third duration. B invested one-fourth of the capital for one-fourth duration. C invested the remaining capital for the whole duration. Out of a profit of ₹17,000, how much profit will C get?
(1) ₹12,000
(2) ₹10,000
(3) ₹12,500
(4) ₹10,750
= 1
~ Profit is shared in the ratio of capital × time. Take the total capital and the full duration each as 1. A: 1/3 × 1/3 = 1/9. B: 1/4 × 1/4 = 1/16. C invests the remaining capital, 1 − 1/3 − 1/4 = 5/12, for the whole duration: 5/12 × 1 = 5/12. Multiplying by 144, A : B : C = 16 : 9 : 60, total 85. C’s share = 60/85 × 17,000 = ₹12,000. Check: A gets ₹3,200 and B ₹1,800, and 3,200 + 1,800 + 12,000 = 17,000. Hence option (a).

Q 79 | qa | Arithmetic
There are two chemicals which do not react with each other. A container contains 10 litres of the chemical A. One litre of this chemical is removed from it and one litre of the chemical B is poured. Then one litre of the mixture is removed from the container and one litre of B is poured. If this process of replacing one litre of the mixture by one litre of B is performed once more, then what is the volume of B that is present in the container approximately (in percentage)?
(1) 25
(2) 27
(3) 29
(4) 31
= 2
~ Each replacement removes one-tenth of the contents and refills with B, so the quantity of A is multiplied by 9/10 each time. Three replacements are made in all (the first, the second, and “once more”). A left = 10 × (0.9)³ = 7.29 litres, so B = 10 − 7.29 = 2.71 litres, i.e., 27.1% of the 10 litres, about 27%. Step check: B is 1 litre after the first replacement, 1.9 litres after the second and 2.71 litres after the third. Hence option (b).

Q 80 | qa | Algebra
A shopkeeper employs a delivery boy and gives him a motorcycle for home delivery. For every delivery, the boy is given ₹5. At the end of the day, he also gets ₹2 for every kilometre of the distance covered in the day. The boy wants to earn more than ₹500 a day, but does not want to travel more than 100 km. Which of the following numbers of deliveries would definitely meet his target?
(1) 80
(2) 85
(3) 90
(4) The question cannot be answered due to insufficient data
= 4
~ Daily earning = 5n + 2d, where n is the number of deliveries and d (at most 100 km) the distance travelled. The distance is not fixed by the number of deliveries, so the kilometre component can be anything from almost nothing up to ₹200. To be certain of more than ₹500, the deliveries alone would have to exceed ₹500, i.e., n ≥ 101. With 80, 85 or 90 deliveries he earns ₹400, ₹425 or ₹450 from deliveries and still needs more than 50, 37.5 or 25 km respectively, which is possible but not guaranteed. So none of the listed numbers definitely meets the target; the data are insufficient. Hence option (d).
