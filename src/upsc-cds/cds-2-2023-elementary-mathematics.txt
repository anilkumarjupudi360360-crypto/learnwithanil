Q 1 | alg | Equations & Expressions
If a² − bc = α, b² − ac = β, c² − ab = γ, then what is (aα + bβ + cγ)/((a + b + c)(α + β + γ)) equal to?
(1) a + b − c
(2) a − b + c
(3) −a + b + c
(4) 1
= 4
~ aα + bβ + cγ = a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca), and α + β + γ = a² + b² + c² − ab − bc − ca. So the ratio is exactly 1.

Q 2 | alg | Polynomials & Quadratics
If (x − 1)³ is a factor of x⁴ + αx³ + βx² + γx − 1, then the other factor will be:
(1) x + 1
(2) x − 3
(3) x + 2
(4) x
= 1
~ The other factor is linear, say (x + k). Comparing constant terms, (−1)³·k = −1, so k = 1. Check: (x − 1)³(x + 1) = x⁴ − 2x³ + 2x − 1.

Q 3 | ari | Number System
A 2-digit number is such that the sum of the number and the number obtained by reversing the order of the digits of the number is 55. Further, the difference of the given number and the number obtained by reversing the order of the digits of the number is 45. What is the product of the digits?
(1) 5
(2) 2
(3) 1
(4) 0
= 4
~ 11(a + b) = 55 gives a + b = 5, and 9(a − b) = 45 gives a − b = 5. So a = 5, b = 0 (the number is 50) and the product of the digits is 0.

Q 4 | ari | Ratio, Time & Work
If A and B can finish a work in 10 days, B and C can finish the same work in 12 days, C and A can finish the same work in 15 days; then in how many days can A, B and C together finish half of the work?
(1) 8 days
(2) 5 days
(3) 4 days
(4) 3 days
= 3
~ 2(A + B + C) = 1/10 + 1/12 + 1/15 = 1/4, so A + B + C = 1/8 of the work per day. The whole work takes 8 days, so half takes 4 days.

Q 5 | ari | Percentage, Profit & Interest

(1) ₹ 927·27
(2) ₹ 947·47
(3) ₹ 967·67
(4) ₹ 987·87
= 1
~ The rate is 3% per quarter for 3 quarters. Interest = 10000(1.03³ − 1) = 10000 × 0.092727 = ₹ 927.27.

Q 6 | trg | Ratios & Identities
For what relation between a and b is the equation sin θ = (a + b)/(2√ab) possible?
(1) a = b
(2) a ≤ b
(3) a ≥ b
(4) a > b
= 1
~ By AM ≥ GM, (a + b)/(2√ab) ≥ 1. Since sin θ ≤ 1, the equation is possible only when the two are equal, i.e. when a = b.

Q 7 | ari | Ratio, Time & Work
Three persons A, B and C together can do a piece of work in 36 days. A and B together can do five times as much work as C alone; B and C together can do as much work as A alone. If A and C together can do n times as much work as B alone, then what is the value of n?
(1) 1·5
(2) 2
(3) 2·5
(4) 3
= 2
~ Daily rates: A + B + C = 1/36. Since A + B = 5C, 6C = 1/36, so C = 1/216. Since B + C = A, 2A = 1/36, so A = 1/72 = 3/216. Then B = 6/216 − 3/216 − 1/216 = 2/216, so A + C = 4/216 = 2B and n = 2.

Q 8 | alg | Equations & Expressions
If 2a/3 = 4b/5 = 3c/4, then what is the value of (18/a)√(a² + c² − b²)?
(1) 3√5
(2) √355
(3) √375
(4) 3√15
= 2
~ Set each ratio equal to k: a = 3k/2, b = 5k/4, c = 4k/3. Then a² + c² − b² = k²(81 + 64 − 56.25)/36 = 355k²/144, so (18/a)·(√355·k/12) = (12/k)(√355·k/12) = √355.

Q 9 | sts | Statistics & Data
The sum of deviations of n numbers from 10 and 20 are a, b respectively. If b/a = −4, then what is the mean of these n numbers?
(1) 12
(2) 14
(3) 16
(4) 18
= 1
~ a = Σx − 10n and b = Σx − 20n = a − 10n. From b = −4a we get 5a = 10n, so a = 2n. The mean is 10 + a/n = 12.

Q 11 | alg | Polynomials & Quadratics
How many real roots does the equation √(x + 9) = x − 3 have?

(3) Only three
(4) None
= 1

Q 13 | ari | Number System
Let L be the LCM and H be the HCF of two given numbers. L and H are in the ratio 3 : 2. If the sum of the two numbers is 45, then what is the product of the numbers?
(1) 243
(2) 486
(3) 504
(4) Cannot be determined due to insufficient data
= 2
~ The keyed value 486 = 27 × 18 comes from the pair 27 and 18, whose sum is 45 and which are themselves in the ratio 3 : 2. Note: UPSC's key gives (2); by standard sources the answer appears to be (4), because the HCF always divides the LCM, so L : H must be a whole number and can never be 3 : 2. The data is inconsistent (27 and 18 actually have L = 54 and H = 9).

Q 15 | alg | Equations & Expressions
If 3ˣ⁻¹ + 3³⁻ˣ = 6, then what is 2ˣ⁻¹ + 2³⁻ˣ equal to?
(1) 4
(2) 3
(3) 2
(4) 1
= 1
~ Let t = 3ˣ⁻¹. Then 3³⁻ˣ = 9/t, so t + 9/t = 6, which gives (t − 3)² = 0 and t = 3, so x = 2. Hence 2¹ + 2¹ = 4.

Q 16 | alg | Equations & Expressions
If x(a − b + ab/(a − b)) = y(a + b − ab/(a + b)) and x + y = 2a³, then what is x − y equal to?
(1) −2b³
(2) −2ab³
(3) 2b³
(4) 2ab³
= 1
~ The left bracket is (a² − ab + b²)/(a − b) and the right bracket is (a² + ab + b²)/(a + b). So x/y = (a³ − b³)/(a³ + b³). With x + y = 2a³ this gives x = a³ − b³ and y = a³ + b³, so x − y = −2b³.

Q 17 | alg | Polynomials & Quadratics
Which one of the following is a factor of 3√3x³ + 2√2y³ − 18xy + 6√6?
(1) √3x + √2y − √3
(2) √3x + √2y − √6
(3) 3x² + 2y² − √18x − √12y − √6xy + 6
(4) 3x² + 2y² + √18x + √12y − √6xy + 6
= 3
~ With p = √3x, q = √2y, r = √6 we have 3pqr = 18xy, so the expression is p³ + q³ + r³ − 3pqr = (p + q + r)(p² + q² + r² − pq − qr − rp). The second factor is 3x² + 2y² + 6 − √6xy − √12y − √18x (checked numerically).

Q 19 | alg | Polynomials & Quadratics
What is the HCF of
acx³ + bcx² + adx² + acdx + bdx + bcd and
adx³ + acx² + bdx² + bcx + acdx + bcd
if HCF (c, d) = 1, c ≠ d?
(1) bx + c
(2) cx + d
(3) ax + d
(4) ax + b
= 4
~ The first expression is (ax + b)(cx² + dx + cd) and the second is (ax + b)(dx² + cx + cd). The remaining quadratic factors have no common factor when c ≠ d, so the HCF is ax + b.

Q 20 | alg | Polynomials & Quadratics
If xⁿ − pyⁿ + qzⁿ is divisible by x² + abyz − bzx − axy, then what is p/aⁿ − q/bⁿ equal to?
(1) −1
(2) 0
(3) 1
(4) 2
= 3
~ The divisor factors as (x − ay)(x − bz). Setting x = ay gives (aⁿ − p)yⁿ + qzⁿ = 0, so p = aⁿ and q = 0. Setting x = bz gives (bⁿ + q)zⁿ − pyⁿ = 0, so p = 0 and q = −bⁿ. Either way, p/aⁿ − q/bⁿ = 1.

Q 21 | ari | Ratio, Time & Work
Consider the following statements:
1. If (a + b) is directly proportional to (a − b), then (a² + b²) is directly proportional to ab.
2. If a is directly proportional to b, then (a² − b²) is directly proportional to ab.
Which of the statements given above is/are correct?
(1) 1 only
(2) 2 only
(3) Both 1 and 2
(4) Neither 1 nor 2
= 3
~ In 1, a + b = k(a − b) gives a = mb for a constant m, so (a² + b²)/ab = (m² + 1)/m, which is constant. In 2, a = kb gives (a² − b²)/ab = (k² − 1)/k, which is also constant. So both statements are true.

Q 22 | alg | Equations & Expressions
If (3a + 6b + c + 2d) × (3a − 6b − c + 2d) = (3a − 6b + c − 2d) × (3a + 6b − c − 2d), then which one of the following is correct?
(1) ab = cd
(2) ac = bd
(3) ad = bc
(4) ad + bc = 0
= 3
~ LHS = (3a + 2d)² − (6b + c)² and RHS = (3a − 2d)² − (6b − c)². LHS − RHS = 24ad − 24bc = 0, so ad = bc.

Q 24 | alg | Equations & Expressions
The combined age of a man and his wife is 6 times the combined age of their children. Two years ago their combined age was 10 times the combined age of their children; and six years later their combined age will be 3 times the combined age of their children. How many children do they have if each child is at least 2 years old?
(1) 2
(2) 3
(3) 4
(4) 5
= 2
~ Let the parents' total be M, the children's total C and the number of children n. Then M = 6C, M − 4 = 10(C − 2n) and M + 12 = 3(C + 6n). This gives 4C = 20n − 4 and 3C = 18n − 12, so n = 3 (C = 14, M = 84).

Q 26 | trg | Ratios & Identities
What is the value of sin θ + cos θ, if θ satisfies the equation cot² θ − (√3 + 1) cot θ + √3 = 0; 0 < θ < π/4?
(1) √2
(2) 2

(4) (√3 − 1)/2

Q 28 | trg | Ratios & Identities
If tan x = (sin θ + cos θ)/(sin θ − cos θ), π/4 < θ < π/2, then what is √2 sin x equal to?

(2) sin θ − cos θ

Q 29 | trg | Ratios & Identities
How many values of θ will satisfy the equation (sin² θ − 4 sin θ + 3) (4 − cos² θ + 4 sin θ) = 0, where 0 < θ < π/2?
(1) None
(2) Only one
(3) Onle two
(4) Only three
= 1
~ The first factor is (sin θ − 1)(sin θ − 3), so sin θ = 1 or 3. The second factor is sin² θ + 4 sin θ + 3 = (sin θ + 1)(sin θ + 3), so sin θ = −1 or −3. None of these is possible for 0 < θ < π/2, where 0 < sin θ < 1.

Q 30 | trg | Ratios & Identities

(4) 3

Q 31 | trg | Heights & Distances
Passage: A flagstaff stands on the top of a vertical tower. The angle of elevation of the top of the flagstaff from a certain place on the same horizontal level with the base of the tower is found to be α. Advancing a distance d towards the tower in the same horizontal plane, the angle of elevation of the top of the flagstaff is observed to be β and that of the top of the tower is observed to be γ. Let H be the height of the top of the flagstaff from the base of the tower and h be the height of the tower.

Which one of the following is correct?
(1) H tan γ − h tan β = 0
(2) h tan γ − H tan β = 0
(3) H tan γ − h tan α = 0
(4) h tan γ − H tan α = 0
= 1
~ From the second point at distance D from the tower, tan β = H/D and tan γ = h/D. So D = H/tan β = h/tan γ, which gives H tan γ = h tan β.

Q 33 | trg | Heights & Distances

The angle of elevation of the top of the tower at Q is twice of that at R. (Use the formula tan 2θ = 2 tan θ/(1 − tan² θ))

Which one of the following is correct?
(1) x = y
(2) x < y
(3) x > y
(4) Cannot be concluded due to insufficient data
= 2
~ Let T be the top of the tower and let the angle at R be θ. The exterior angle at Q is 2θ, so ∠QTR = θ and triangle QTR is isosceles with QT = QR = y. QT is the hypotenuse of right triangle TPQ, so y = QT > QP = x.

Q 37 | alg | Equations & Expressions
Passage: Let p = x⁴ − y²z², q = y⁴ − z²x², r = z⁴ − x²y².

What is px² + qy² + rz² equal to?
(1) (x² + y² + z²) (p + q + r)
(2) −(x² + y² + z²) (p + q + r)
(3) (y² + z² − x²) (r − q − p)
(4) (x² + y² − z²) (p − q − r)
= 1
~ Put a = x², b = y², c = z². Then px² + qy² + rz² = a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca), and p + q + r is exactly the second factor. So the expression equals (x² + y² + z²)(p + q + r) (verified numerically).

Q 38 | alg | Equations & Expressions
Passage: Let p = x⁴ − y²z², q = y⁴ − z²x², r = z⁴ − x²y².

What is x² (px² + qy² + rz²) + qr − p² equal to?
(1) 0
(2) 1
(3) p + q + r
(4) x² + y² + z²
= 1
~ With a = x², b = y², c = z²: qr − p² = (b² − ca)(c² − ab) − (a² − bc)² = a(a³ + b³ + c³ − 3abc) = −x²(px² + qy² + rz²). So the whole expression is 0 (numerically checked).

Q 39 | gm | Mensuration
Passage: A right conical cap just covers two spheres placed one above the other on a table such that it touches both the spheres. Let r be the radius of the smaller sphere and R be the radius of the bigger sphere. Let 2θ be the vertical angle of the cone.

What is the height of the cone?
(1) 2r²/(R − r)
(2) 2R²/(R − r)
(3) 2(r² + R²)/(R − r)
(4) (r² + R²)/(R − r)
= 2
~ The spheres touch each other and the cone, so sin θ = (R − r)/(R + r). The centre of the big sphere is at height R and lies R/sin θ below the apex. So height = R + R(R + r)/(R − r) = 2R²/(R − r).

Q 41 | gm | Circles & Quadrilaterals
Passage: A line segment AB is bisected at C and semi-circles S₁, S₂ and S₃ are drawn respectively on AB, AC and CB as diameters such that they all lie on same side of AB. A circle S is drawn touching internally S₁ and externally S₂ and S₃.

If r is the radius of S and R is the radius of S₂, then which one of the following is correct?
(1) R = 3r
(2) R = 2r
(3) 3R = 4r
(4) 2R = 3r
= 4
~ Take C as the origin. S₁ has radius 2R, and S₂, S₃ have centres (∓R, 0). Let S have centre (0, k) with k = 2R − r. Tangency to S₂ gives R² + (2R − r)² = (R + r)², so 4R² = 6Rr and 2R = 3r.

Q 42 | gm | Circles & Quadrilaterals

Q 43 | alg | Equations & Expressions
Passage: Let (x − a)(x − b)/((x − ma)(x − mb)) = (x + a)(x + b)/((x + ma)(x + mb)); m, a, b > 0.

What is (x² + ab)/(x² + m²ab) equal to?
(1) −1/m²
(2) 1/m²
(3) 2/m
(4) 1/m
= 4
~ Let u = x² + ab, v = x² + m²ab and s = a + b. Cross-multiplying gives (u − sx)(v + msx) = (u + sx)(v − msx), so mu = v, i.e. u/v = 1/m.

Q 45 | alg | Equations & Expressions
Passage: The total monthly electricity bill for a house consists of the sum of two parts, one part is proportional to number of rooms and the other part is proportional to number of units consumed. ₹ 400 is the monthly electricity bill for a house with 8 rooms and consuming 240 units and ₹ 320 is the monthly electricity bill for a house with 6 rooms and consuming 200 units.

What is the monthly electricity bill for a house with m rooms and consuming n units?
