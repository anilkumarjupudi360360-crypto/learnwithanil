Q 1 | mat | Matrices
Let X be a matrix of order 3×3, Y be a matrix of order 2×3 and Z be a matrix of order 3×2. Which of the following statements are correct?
I. (ZY)X is defined and is a square matrix of order 3.
II. Y(XZ) is defined and is a square matrix of order 2.
III. X(YZ) is not defined.
Select the answer using the code given below.
(1) I and II only
(2) II and III only
(3) I and III only
(4) I, II and III
= 4
~ ZY is (3×2)(2×3) = 3×3, so (ZY)X is 3×3; XZ is 3×2, so Y(XZ) is (2×3)(3×2) = 2×2; YZ is 2×2 and X is 3×3, so X(YZ) is not defined. All three are correct.

Q 2 | alg | Sets, Relations & Functions
Consider the following statements :
I. The set of all irrational numbers between √12 and √15 is an infinite set.
II. The set of all odd integers less than 1000 is a finite set.
Which of the statements given above is/are correct?
(1) I only
(2) II only
(3) Both I and II
(4) Neither I nor II
= 1
~ Between any two distinct reals there are infinitely many irrationals, so I is true. Odd integers less than 1000 include all negative odd integers (…, −3, −1, 1, …, 999), so the set is infinite and II is false.

Q 4 | alg | Complex Numbers
If ω ≠ 1 is a cube root of unity, then what is (1 + ω − ω²)¹⁰⁰ + (1 − ω + ω²)¹⁰⁰ equal to?
(1) 2¹⁰⁰ω²
(2) 2¹⁰⁰ω
(3) 2¹⁰⁰
(4) −2¹⁰⁰
= 4
~ 1 + ω − ω² = −2ω² and 1 − ω + ω² = −2ω, so the sum is 2¹⁰⁰(ω²⁰⁰ + ω¹⁰⁰) = 2¹⁰⁰(ω² + ω) = −2¹⁰⁰.

Q 5 | mat | Matrices
Let A and B be two square matrices of same order. If AB is a null matrix, then which one of the following is correct?
(1) Both A and B are null matrices
(2) Either A or B is a null matrix
(3) B is a null matrix if A is a non-singular matrix
(4) Both A and B are singular matrices
= 3
~ If A is non-singular, multiply AB = O on the left by A⁻¹ to get B = O. Options (1), (2) fail because two non-zero matrices can have a zero product, and (4) fails when A is invertible and B = O.

Q 6 | alg | Binomial Theorem
In the expansion of (1 + x)ᵖ (1 + x)^q, if the coefficient of x³ is 35, then what is the value of (p + q)?
(1) 5
(2) 6
(3) 7
(4) 8
= 3
~ (1 + x)ᵖ(1 + x)^q = (1 + x)^(p+q), so the coefficient of x³ is C(p+q, 3) = 35, which gives p + q = 7 (C(7, 3) = 35).

Q 7 | alg | Sequences & Series
If p times the pth term of an AP is equal to q times the qth term (p ≠ q), then what is the (p + q)th term equal to?
(1) 0
(2) p + q
(3) pq
(4) pq(p + q)
= 1
~ p[a + (p−1)d] = q[a + (q−1)d] gives (p − q)[a + (p + q − 1)d] = 0; since p ≠ q, a + (p + q − 1)d = 0, which is exactly the (p + q)th term.

Q 8 | alg | Sequences & Series
Let p = ln(x), q = ln(x³) and r = ln(x⁵), where x > 1. Which of the following statements is/are correct?

II. p, q and r can never be in GP.
Select the answer using the code given below.
(1) I only
(2) II only
(3) Both I and II
(4) Neither I nor II
= 3
~ p, q, r = ln x, 3 ln x, 5 ln x, which are in AP. For a GP we would need q² = pr, i.e. 9(ln x)² = 5(ln x)², impossible since ln x ≠ 0 for x > 1; so both statements hold.

Q 12 | mat | Determinants

Q 16 | alg | Quadratic Equations & Inequalities
If n is a root of the equation x² + px + m = 0 and m is a root of the equation x² + px + n = 0, where m ≠ n, then what is the value of p + m + n?

Q 17 | alg | Permutations & Combinations

(4) (n − 2)(n − 3)/2

Q 19 | mat | Matrices
Consider the following in respect of the matrices P = [[0, c, −b], [−c, 0, a], [b, −a, 0]] and Q = [[a², ab, ac], [ab, b², bc], [ac, bc, c²]]
I. PQ is a null matrix.
II. QP is an identity matrix of order 3.
III. PQ = QP
Which of the above is/are correct?
(1) I only
(2) II only
(3) I and III
(4) II and III
= 3
~ Q = vvᵀ with v = (a, b, c), and Pv = (cb − bc, −ca + ac, ab − ab) = 0, so PQ = (Pv)vᵀ = O; also QP = v(Pᵀv)ᵀ = −v(Pv)ᵀ = O. Hence PQ = QP = O, and II is false.

Q 20 | mat | Determinants

(4) 3

Q 24 | trg | Ratios & Identities
The roots of the equation 7x² − 6x + 1 = 0 are tan α and tan β, where 2α and 2β are the angles of a triangle. Which one of the following is correct?

(3) The triangle is right-angled

Q 34 | alg | Sets, Relations & Functions
Let P and Q be two non-void relations on a set A. Which of the following statements are correct?
I. P and Q are reflexive ⇒ P ∩ Q is reflexive.
II. P and Q are symmetric ⇒ P ∪ Q is symmetric.
III. P and Q are transitive ⇒ P ∩ Q is transitive.
Select the answer using the code given below.
(1) I and II only
(2) II and III only
(3) I and III only
(4) I, II and III
= 4
~ Every (a, a) lies in both P and Q, so in P ∩ Q; if (a, b) ∈ P ∪ Q then (b, a) is in the same relation, so in P ∪ Q; and if (a, b), (b, c) ∈ P ∩ Q, transitivity of each gives (a, c) ∈ P ∩ Q. All three hold.

Q 47 | alg | Quadratic Equations & Inequalities
Passage: The roots of the quadratic equation a²(b² − c²)x² + b²(c² − a²)x + c²(a² − b²) = 0 are equal (a² ≠ b² ≠ c²).

(2) a², b², c² are in GP.
