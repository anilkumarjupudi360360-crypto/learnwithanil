Q 1 | alg | Complex Numbers
If ω is a non-real cube root of 1, then what is the value of |(1 − ω)/(ω + ω²)| ?
(1) √3
(2) √2
(3) 1
(4) 4/√3
= 1
~ Since 1 + ω + ω² = 0, ω + ω² = −1, so the denominator has modulus 1. |1 − ω| = |1 − (−1/2 + i√3/2)| = |3/2 − i√3/2| = √(9/4 + 3/4) = √3.

Q 2 | alg | Permutations & Combinations
What is the number of 6-digit numbers that can be formed only by using 0, 1, 2, 3, 4 and 5 (each once); and divisible by 6 ?
(1) 96
(2) 120
(3) 192
(4) 312
= 4
~ Digit sum 15 is divisible by 3, so every such number is divisible by 3; it only needs to be even. Last digit 0: 5! = 120; last digit 2 or 4: 2 × (4 × 4!) = 192; total 120 + 192 = 312.

Q 4 | mat | Determinants

(3) 17
(4) 24

Q 5 | alg | Complex Numbers

Q 6 | mat | Matrices
Let A and B be symmetric matrices of same order, then which one of the following is correct regarding (AB − BA) ?
1. Its diagonal entries are equal but nonzero
2. The sum of its non-diagonal entries is zero
Select the correct answer using the code given below :
(1) 1 only
(2) 2 only
(3) Both 1 and 2
(4) Neither 1 nor 2
= 2
~ (AB − BA)ᵀ = BA − AB, so AB − BA is skew-symmetric. Its diagonal entries are all zero, so statement 1 is false. Its off-diagonal entries come in pairs aᵢⱼ = −aⱼᵢ, so they add up to zero.

Q 7 | mat | Matrices
Consider the following statements in respect of square matrices A, B, C each of same order n :
1. AB = AC ⇒ B = C if A is non-singular
2. If BX = CX for every column matrix X having n rows then B = C
Which of the statements given above is/are correct ?
(1) 1 only
(2) 2 only
(3) Both 1 and 2
(4) Neither 1 nor 2
= 3
~ If A is non-singular, multiplying AB = AC by A⁻¹ gives B = C. If BX = CX for every X, take X as each unit column vector eⱼ: then every column of B equals the matching column of C, so B = C.

Q 8 | mat | Determinants
The system of linear equations x + 2y + z = 4, 2x + 4y + 2z = 8 and 3x + 6y + 3z = 10 has
(1) a unique solution
(2) infinite many solutions
(3) no solution
(4) exactly three solutions
= 3
~ The first equation gives x + 2y + z = 4, so 3x + 6y + 3z = 12. This contradicts 3x + 6y + 3z = 10, so the system is inconsistent. In rank terms, rank of the coefficient matrix is 1 and rank of the augmented matrix is 2.

Q 9 | mat | Matrices

Q 10 | mat | Determinants
What is the sum of the roots of the equation |[[0, x − a, x − b], [0, 0, x − c], [x + b, x + c, 1]]| = 0 ?
(1) a + b + c
(2) a − b + c
(3) a + b − c
(4) a − b − c
= 2

Q 17 | alg | Quadratic Equations & Inequalities

(2) 4
(3) 5
(4) 6
= 2

Q 22 | alg | Sets, Relations & Functions
A mapping f : A → B defined as f(x) = (2x + 3)/(3x + 5), x ∈ A. If f is to be onto, then what are A and B equal to ?
(1) A = R∖{−5/3} and B = R∖{−2/3}
(2) A = R and B = R∖{−5/3}
