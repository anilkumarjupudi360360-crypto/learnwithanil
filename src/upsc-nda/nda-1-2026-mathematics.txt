Q 1 | alg | Sequences & Series
Let p, q and r be three unequal numbers such that p, q and r are in AP. If (q − p), (r − q) and p are in GP, then (p + q) : (q + r) : (r + p) equals
(1) 1 : 2 : 3
(2) 3 : 4 : 5
(3) 3 : 5 : 4
(4) 1 : 3 : 2
= 3
~ Let q − p = r − q = d (d ≠ 0). The GP d, d, p has ratio 1, so p = d, giving p = d, q = 2d, r = 3d. Then (p + q) : (q + r) : (r + p) = 3d : 5d : 4d = 3 : 5 : 4.

Q 2 | alg | Sequences & Series
If p, g₁, g₂ and q are in GP and m is the arithmetic mean of p and q, then g₁²/g₂ + g₂²/g₁ is equal to
(1) m
(2) 2m
(3) 1
(4) 1/2
= 2
~ With ratio r: g₁ = pr, g₂ = pr², q = pr³. Then g₁²/g₂ + g₂²/g₁ = (g₁³ + g₂³)/(g₁g₂) = p³r³(1 + r³)/(p²r³) = p + pr³ = p + q = 2m.

Q 3 | alg | Complex Numbers
Consider the following inequalities:
I. 1 + 4i > 3 + 2i
II. 2 + 3i < 3 + 4i
III. 4 + 3i > 3 + 4i
where i = √−1
How many of the above are valid?
(1) None
(2) One
(3) Two
(4) All the three
= 1
~ Complex numbers with non-zero imaginary parts cannot be ordered: there is no "greater than" or "less than" between them. So none of the three inequalities is meaningful or valid.

Q 4 | alg | Complex Numbers
Let Z₁ and Z₂ be complex numbers such that 3Z₁/(4Z₂) is purely imaginary. What is |(Z₁ + Z₂)/(Z₁ − Z₂)| equal to?
(1) 2
(2) 3/2
(3) 5/4
(4) 1
= 4
~ Z₁/Z₂ = it for some real t ≠ 0. Then |(Z₁ + Z₂)/(Z₁ − Z₂)| = |it + 1|/|it − 1| = √(t² + 1)/√(t² + 1) = 1.

Q 5 | alg | Complex Numbers
If α, β, γ are cube roots of −8, then what is (α²p² + β²q² + γ²r²)/(β²p² + γ²q² + α²r²) equal to?
(1) γ/α
(2) γ/β
(3) 2γ/α
(4) 2γ/β
= 2
~ The cube roots are −2, −2ω, −2ω². Taking β = αω, γ = αω²: numerator = α²(p² + ω²q² + ωr²) and denominator = α²ω²(p² + ω²q² + ωr²), so the ratio is 1/ω² = ω = γ/β (the same result holds for the other ordering).

Q 7 | alg | Sets, Relations & Functions
A set S contains (2n + 1) elements. If the number of subsets of S which contain at most n elements is 1024, then what is the value of n?
(1) 10
(2) 8
(3) 6
(4) 5
= 4
~ Since C(2n+1, k) = C(2n+1, 2n+1−k), exactly half of the 2²ⁿ⁺¹ subsets have at most n elements, i.e. 2²ⁿ = 1024 = 2¹⁰, so n = 5.

Q 8 | alg | Permutations & Combinations

(1) 10
(2) 15
(3) 20
(4) 25
= 3

Q 9 | alg | Permutations & Combinations
What is the greatest value of r satisfying the inequality ¹⁵Cᵣ₊₁ > 2 × ¹⁵Cᵣ?

Q 10 | alg | Permutations & Combinations
If n = ᵐC₂ then what is ⁿC₂ equal to?

(2) 2 × ᵐ⁺¹C₄

Q 11 | alg | Quadratic Equations & Inequalities
If the highest degree coefficient is equal to 1, then what is the total number of quadratic equations which are unchanged on squaring their roots?
(1) 6
(2) 4
(3) 2
(4) None
= 2
~ The roots {α, β} must equal {α², β²}. Either α = α², β = β² (roots 0, 0; 1, 1; 0, 1) or α = β², β = α² (giving ω, ω²). So the equations are x² = 0, x² − 2x + 1 = 0, x² − x = 0 and x² + x + 1 = 0: four in all.

Q 12 | alg | Quadratic Equations & Inequalities
Let α and β be the roots of the quadratic equation x² − 2bx + c² = 0 where b, c are positive real numbers. Let A be the arithmetic mean of α and β; and G be the geometric mean of α and β. What are the roots of the quadratic equation x² − (b + c)x + bc = 0?
(1) A, G
(2) 2A, G
(3) A, 2G
(4) 2A, 2G
= 1
~ α + β = 2b and αβ = c², so A = b and G = √(c²) = c. The equation x² − (b + c)x + bc = (x − b)(x − c) = 0 has roots b and c, i.e. A and G.

Q 14 | cal | Differentiation & Applications
Let f(x) = |[3x², cos x, −sin x], [6, −1, 0], [q, q², q³]| (a determinant), where q is any constant, then what is d²/dx² (f(x)) at x = 0 equal to?
(1) −1
(2) 0
(3) 1
(4) q
= 2
~ Only the first row depends on x, so f''(x) is the determinant with first row (6, −cos x, sin x). At x = 0 this row is (6, −1, 0), identical to the second row, so f''(0) = 0.

Q 15 | mat | Determinants
If |[a − b, p − q, x − y], [b − c, q − r, y − z], [c − a, r − p, z − x]| = k |[a, b, c], [p, q, r], [x, y, z]|, then what is the value of k?

(3) 1/2
(4) 1

Q 16 | mat | Determinants
If p, q, r are the cube roots of unity, then what is |[p² + q², r², r²], [p², q² + r², p²], [q², q², r² + p²]| equal to?
(1) −1
(2) 0
(3) 1
(4) 4
= 4
~ This is the standard determinant |[b + c, a, a], [b, c + a, b], [c, c, a + b]| = 4abc with a = r², b = p², c = q², so its value is 4p²q²r² = 4(pqr)² = 4 × 1² = 4 (pqr = 1·ω·ω² = 1).

Q 18 | mat | Matrices
Consider the following statements:
I. If n × n (n > 1) matrix is symmetric, then its inverse is also a symmetric matrix.
II. If n × n (n > 1) matrix is singular, then its adjoint is also a singular matrix.
Which of the statements given above is/are correct?
(1) I only
(2) II only
(3) Both I and II
(4) Neither I nor II
= 3
~ I: (A⁻¹)ᵀ = (Aᵀ)⁻¹ = A⁻¹, so the inverse (when it exists) is symmetric. II: |adj A| = |A|ⁿ⁻¹ = 0 when |A| = 0, so adj A is singular. Both are correct.

Q 20 | mat | Determinants
If Mₖ = [[k, k − 1], [k − 1, k]] where k is a natural number, then what is |M₁| + |M₂| + |M₃| + ... + |M₅₀| equal to?

(4) 5000

Q 21 | mat | Determinants
If Mᵀ is the transpose of a 2 × 2 matrix M, then which of the following is/are correct?
I. |M + Mᵀ| = |M| + |Mᵀ| if M is symmetric.
II. |M + Mᵀ| = 0 if M is anti-symmetric.
Select the answer using the code given below:
(1) I only
(2) II only
(3) Both I and II
(4) Neither I nor II
= 2
~ I: if M is symmetric, |M + Mᵀ| = |2M| = 4|M| whereas |M| + |Mᵀ| = 2|M|; these differ unless |M| = 0 (e.g. M = [[1, 2], [2, 5]] gives 4 vs 2), so I is false. II: if M is anti-symmetric, M + Mᵀ = O, so its determinant is 0; II is true.

Q 22 | mat | Determinants
If M is a square matrix such that M³ = M, then how many values of |M| are possible?

(2) Two
(3) Three
(4) Four

Q 23 | mat | Determinants
Let p = (x + y + z) and q = xyz. If |[x, 1, 1], [1, y, 1], [1, 1, z]| is positive, then which one of the following is correct?

(2) q + 1 > p
(3) q + 2 > p

Q 24 | alg | Sets, Relations & Functions
What is (((A ∩ B) ∪ (A − B)) − ((A ∩ B) ∪ (B − A))) ∪ A equal to?
(1) φ
(2) A
(3) B

Q 25 | alg | Sets, Relations & Functions
Let A and B be two sets. For some set C, both A ∩ C and B ∩ C are empty sets and A ∪ C = B ∪ C. Which of the following is/are true?
I. C = φ
II. A = B
III. A ∪ B = C
Select the answer using the code given below:
(1) I only
(2) II only
(3) I and II only
(4) I, II and III
= 2
~ Since A and B are both disjoint from C, A = (A ∪ C) − C = (B ∪ C) − C = B, so II is true. C need not be empty (A = B = {1}, C = {2} works), and then A ∪ B ≠ C, so I and III are not necessarily true.

Q 26 | trg | Ratios & Identities
If 2 sec 4β = tan 2α + cot 2α, then which one of the following is a possible value of (α + β)?
(1) π/2
(2) π/4
(3) π/6
(4) π/8
= 4
~ tan 2α + cot 2α = 1/(sin 2α cos 2α) = 2/sin 4α, so 2/cos 4β = 2/sin 4α, i.e. sin 4α = cos 4β. One solution is 4α + 4β = π/2, giving α + β = π/8.

Q 27 | trg | Ratios & Identities
If α and β are complementary angles such that α − β = π/6 and m tan β = n tan α, then what is ((m + n)/(m − n)) equal to?
(1) 2
(2) 2/√3
(3) 1
(4) 1/√3
= 1
~ α + β = π/2 and α − β = π/6 give α = π/3, β = π/6. Then m/n = tan α/tan β = √3/(1/√3) = 3, so (m + n)/(m − n) = (3 + 1)/(3 − 1) = 2.

Q 28 | trg | Ratios & Identities
If x = secθ − tanθ and y = cosecθ + cotθ, then which one of the following is correct?
(1) x + y − xy − 1 = 0
(2) x − y + xy + 1 = 0
(3) x + y + xy − 1 = 0
(4) x − y − xy − 1 = 0
= 2
~ x = (1 − sinθ)/cosθ and y = (1 + cosθ)/sinθ; then x − y + xy + 1 = [(1 − sinθ)sinθ − (1 + cosθ)cosθ + (1 − sinθ)(1 + cosθ) + sinθcosθ]/(sinθcosθ) = (1 − sin²θ − cos²θ)/(sinθcosθ) = 0. (Checked numerically at θ = 0.7.)

Q 33 | trg | Properties of Triangles

(2) √2
(3) √3

Q 36 | trg | Properties of Triangles

Q 37 | trg | Properties of Triangles

Q 46 | alg | Binomial Theorem
Passage: For the next five (05) items that follow:
Let u be a positive integer and f be a real number lying between 0 and 1. Further, (√2 + 1)¹⁰ = u + f and (√2 − 1)¹⁰ = v
Consider the following statements:
I. (u + v + f) is an integer.
II. (f + v) is an integer.

Which of the statements given above is/are correct?
(1) I only
(2) II only
(3) Both I and II
(4) Neither I nor II
= 3
~ (√2 + 1)¹⁰ + (√2 − 1)¹⁰ is an integer (the odd powers of √2 cancel), so u + f + v is an integer. Then f + v = integer − u is an integer, and since 0 < f, v < 1, f + v = 1. Both are correct.
