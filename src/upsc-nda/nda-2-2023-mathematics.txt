Q 1 | alg | Complex Numbers
If zz̄ = |z + z̄|, where z = x + iy, i = √(−1), then the locus of z is a pair of:
(1) straight lines
(2) rectangular hyperbolas
(3) parabolas
(4) circles
= 4
~ zz̄ = x² + y² and z + z̄ = 2x, so x² + y² = 2|x|, i.e. x² + y² − 2x = 0 or x² + y² + 2x = 0. These are two circles of radius 1 centred at (1, 0) and (−1, 0).

Q 2 | alg | Sequences & Series
If 1! + 3! + 5! + 7! + ... + 199! is divided by 24, what is the remainder?
(1) 3
(2) 6
(3) 7
(4) 9
= 3
~ Every n! with n ≥ 4 is divisible by 24, so only 1! + 3! = 1 + 6 = 7 matters. The remainder is 7.

Q 3 | alg | Complex Numbers
What is the value of √(12 + 5i) + √(12 − 5i), where i = √(−1)?
(1) 24
(2) 25
(3) 5√2
(4) 5(√2 − 1)
= 3
~ |12 + 5i| = 13, so √(12 + 5i) = √((13+12)/2) + i√((13−12)/2) = 5/√2 + i/√2. Similarly √(12 − 5i) = 5/√2 − i/√2. Their sum is 10/√2 = 5√2.

Q 7 | mat | Determinants

where I is the identity matrix of order 3?
(1) −1
(2) 0

Q 8 | mat | Matrices
If A = [[0, 3, 4], [−3, 0, 5], [−4, −5, 0]], then which one of the following statements is correct?
(1) A² is symmetric matrix with det(A²) = 0.
(2) A² is symmetric matrix with det(A²) ≠ 0.
(3) A² is skew-symmetric matrix with det(A²) = 0.
(4) A² is skew-symmetric matrix with det(A²) ≠ 0.
= 1
~ A is skew-symmetric (A′ = −A), so (A²)′ = (A′)² = A², which makes A² symmetric. A is skew-symmetric of odd order, so det(A) = 0 and det(A²) = (det A)² = 0.

Q 9 | mat | Matrices
If A = [[2, 0, 0], [0, 3, 0], [0, 0, 4]], then which of the following statements are correct?
1. Aⁿ will always be singular for any positive integer n.
2. Aⁿ will always be a diagonal matrix for any positive integer n.
3. Aⁿ will always be a symmetric matrix for any positive integer n.
Select the correct answer using the code given below:
(1) 1 and 2 only
(2) 2 and 3 only
(3) 1 and 3 only
(4) 1, 2 and 3
= 2
~ Aⁿ = diag(2ⁿ, 3ⁿ, 4ⁿ), which is diagonal and therefore symmetric. Its determinant is 24ⁿ ≠ 0, so Aⁿ is never singular and statement 1 is false.

Q 10 | alg | Sequences & Series
If (a + b), 2b, (b + c) are in HP, then which one of the following is correct?
(1) a, b and c are in AP
(2) a − b, b − c and c − a are in AP
(3) a, b and c are in GP
(4) a − b, b − c and c − a are in GP
= 3
~ HP means 2b = 2(a + b)(b + c)/(a + 2b + c). This gives b(a + 2b + c) = (a + b)(b + c), i.e. ab + 2b² + bc = ab + ac + b² + bc, so b² = ac and a, b, c are in GP.

Q 11 | alg | Sequences & Series
Let t₁, t₂, t₃ ... be in GP. What is (t₁t₃ ... t₂₁)^(1/11) equal to?
(1) t₁₀
(2) t₁₀²
(3) t₁₁
(4) t₁₁²
= 3
~ t₁, t₃, …, t₂₁ are 11 terms that form a GP with middle term t₁₁, and terms equidistant from the ends multiply to t₁₁². So the product is t₁₁¹¹, and its 11th root is t₁₁.

Q 21 | alg | Sets, Relations & Functions
The Cartesian product A × A has 16 elements among which are (0, 2) and (1, 3). Which of the following statements is/are correct?
1. It is possible to determine set A.
2. A × A contains the element (3, 2).
Select the correct answer using the code given below:
(1) 1 only
(2) 2 only
(3) Both 1 and 2
(4) Neither 1 nor 2
= 3
~ |A|² = 16 gives |A| = 4. The pairs (0, 2) and (1, 3) show that 0, 1, 2 and 3 are all in A, so A = {0, 1, 2, 3}. Since 3 and 2 are both in A, (3, 2) is in A × A.

Q 22 | alg | Sets, Relations & Functions
Let A = {1, 2, 3, ..., 20}. Define a relation R from A to A by R = {(x, y) : 4x − 3y = 1}, where x, y ∈ A. Which of the following statements is/are correct?
1. The domain of R is {1, 4, 7, 10, 13, 16}.
2. The range of R is {1, 5, 9, 13, 17}.
3. The range of R is equal to codomain of R.
Select the correct answer using the code given below:
(1) 1 only
(2) 2 only
(3) 1 and 2
(4) 2 and 3
= 2
~ y = (4x − 1)/3 gives R = {(1,1), (4,5), (7,9), (10,13), (13,17)}. x = 16 would need y = 21, which is not in A, so the domain is {1, 4, 7, 10, 13} and statement 1 is wrong. The range {1, 5, 9, 13, 17} is not the whole codomain A.

Q 23 | alg | Sets, Relations & Functions
Consider the following statements:
1. The relation f defined by f(x) = x³ for 0 ≤ x ≤ 2, and f(x) = 4x for 2 ≤ x ≤ 8, is a function.
2. The relation g defined by g(x) = x² for 0 ≤ x ≤ 4, and g(x) = 3x for 4 ≤ x ≤ 8, is a function.
Which of the statements given above is/are correct?
(1) 1 only
(2) 2 only
(3) Both 1 and 2
(4) Neither 1 nor 2
= 1
~ At the common point x = 2, f gives 2³ = 8 and 4 × 2 = 8, so f is well defined. At x = 4, g gives 16 and 12, so it assigns two values and is not a function.

Q 24 | alg | Sets, Relations & Functions
Consider the following statements:
1. A = (A ∪ B) ∪ (A − B)
2. A ∪ (B − A) = (A ∪ B)
3. B = (A ∪ B) − (A − B)
Which of the statements given above are correct?
(1) 1 and 2 only
(2) 2 and 3 only
(3) 1 and 3 only
(4) 1, 2 and 3
= 2
~ (A ∪ B) ∪ (A − B) = A ∪ B, which equals A only when B ⊆ A, so statement 1 is false in general. A ∪ (B − A) = A ∪ B. Removing from A ∪ B the elements that are only in A leaves exactly B.

Q 29 | trg | Ratios & Identities
